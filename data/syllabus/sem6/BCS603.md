# BCS603 — Full Stack Web Development

- **Semester**: 6th Semester B.E. (CSE Core)
- **Course Code**: BCS603
- **Credits**: 4 (3:0:2:0 - IPCC Integrated Course)
- **Total Teaching Hours**: 50 Hours (10 Hours per module)
- **Evaluation**: Continuous Internal Evaluation (CIE): 50 Marks | Semester End Exam (SEE): 50 Marks

---

## Module 1: Front-End Foundations & Modern JavaScript (ES6+)

### Topics Covered
- **Modern JavaScript Core**: ES6+ syntax features (Arrow functions, Destructuring, Spread/Rest operators, Template Literals, Promises, Async/Await), DOM Manipulation, Event Listeners, Modules (ESM vs CommonJS).
- **Responsive Layout Systems**: Advanced CSS3 (Flexbox, Grid Layout, Media Queries for Mobile Responsiveness), CSS Frameworks (Tailwind CSS, Bootstrap 5 architecture).

### Prescribed Textbooks
- Text Book 1: Jon Duckett, *JavaScript and JQuery: Interactive Front-End Web Development*, Wiley.

---

## Module 2: React.js & Single Page Applications (SPA)

### Topics Covered
- **React Fundamentals**: Component-driven architecture, JSX syntax, Virtual DOM, Functional Components vs Class Components, Props, State management (`useState`, `useEffect` hooks).
- **Advanced React & Routing**: React Router v6 (Client-side routing, Dynamic parameters, Protected routes), Form handling in React, Context API (`useContext`), Custom Hooks.

### Prescribed Textbooks
- Text Book 2: Robin Wieruch, *The Road to React: Your journey to master React.js with JavaScript*, Independently Published.

---

## Module 3: Node.js & Express.js Backend Development

### Topics Covered
- **Node.js Runtime**: Event Loop, Non-blocking I/O, Node Package Manager (NPM), File System (FS) module, HTTP module, Streams, Events.
- **Express.js Web Framework**: Routing in Express, Middleware architecture (Built-in, Custom, Error-handling middleware), Handling JSON request bodies, Express Router, Building RESTful API endpoints.

### Prescribed Textbooks
- Text Book 3: Azat Mardan, *Express.js Guide: The Comprehensive Book on Express.js*, Apress.

---

## Module 4: NoSQL Databases & MongoDB Integration

### Topics Covered
- **NoSQL & MongoDB**: Relational vs NoSQL databases, Document database concept, MongoDB CRUD operations using Mongo Shell.
- **Mongoose ODM**: Mongoose Schemas, Models, Data validation, Mongoose Middleware, Population (Document references/relationships), Connecting Express backend to MongoDB Atlas.

### Prescribed Textbooks
- Text Book 3: Azat Mardan, *Express.js Guide: The Comprehensive Book on Express.js*, Apress.

---

## Module 5: Full Stack Integration, Authentication & Deployment

### Topics Covered
- **Authentication & Security**: JSON Web Tokens (JWT) authentication flow, Password hashing using bcrypt, CORS (Cross-Origin Resource Sharing), Rate limiting, Helmet security headers.
- **Full Stack Integration & Deployment**: Connecting React frontend with Express API via Axios/Fetch, State persistence, CI/CD basics, Deploying MERN stack apps to Cloud platforms (Vercel, Render, AWS EC2).

### Prescribed Textbooks
- Text Book 2: Robin Wieruch, *The Road to React*.
- Text Book 3: Azat Mardan, *Express.js Guide*.
