# BCS605A — Blockchain Technology (Professional Elective - II)

- **Semester**: 6th Semester B.E. (CSE)
- **Course Code**: BCS605A / BCS613A
- **Credits**: 3 (3:0:0:0)
- **Total Teaching Hours**: 40 Hours (8 Hours per module)
- **Evaluation**: Continuous Internal Evaluation (CIE): 50 Marks | Semester End Exam (SEE): 50 Marks

---

## Module 1: Blockchain Fundamentals & Cryptography

### Topics Covered
- **Blockchain Overview**: Centralized vs Decentralized vs Distributed systems, History of Blockchain, Distributed Ledger Technology (DLT) architecture, Generic Blockchain structure (Block header, Block body, Block hash, Previous block hash, Nonce, Timestamp).
- **Cryptographic Foundations**: Cryptographic Hash functions (SHA-256 properties, Collision resistance), Merkle Trees (Merkle Root computation and verification), Public Key Cryptography (Elliptic Curve Cryptography - ECDSA), Digital Signatures.

### Prescribed Textbooks
- Text Book 1: Imran Bashir, *Mastering Blockchain: Distributed ledger technology, decentralization, and smart contracts explained*, 3rd/4th Edition, Packt Publishing.

---

## Module 2: Bitcoin Architecture & Consensus Mechanisms

### Topics Covered
- **Bitcoin Architecture**: Bitcoin network protocol, UTXO (Unspent Transaction Output) model vs Account model, Bitcoin transactions, Scripting language, Wallet types (Hot vs Cold wallets, Deterministic wallets).
- **Consensus Algorithms**: Byzantine Generals Problem, Proof of Work (PoW - Difficulty target, Mining, 51% Attack), Proof of Stake (PoS), Delegated Proof of Stake (DPoS), Proof of Authority (PoA), Practical Byzantine Fault Tolerance (PBFT).

### Prescribed Textbooks
- Text Book 1: Imran Bashir, *Mastering Blockchain*, Packt Publishing.
- Reference Book: Andreas M. Antonopoulos, *Mastering Bitcoin: Programming the Open Blockchain*, 2nd Edition, O'Reilly Media.

---

## Module 3: Ethereum & Smart Contracts Programming

### Topics Covered
- **Ethereum Virtual Machine (EVM)**: Ethereum platform architecture, Ether cryptocurrency, Gas mechanism (Gas limit, Gas price), EVM Bytecode, State transition function.
- **Smart Contracts in Solidity**: Solidity syntax, Data types, State variables, Functions, Modifiers, Events, Inheritance, Payable functions, Writing, Compiling (Truffle/Hardhat/Remix), and Deploying smart contracts.

### Prescribed Textbooks
- Text Book 1: Imran Bashir, *Mastering Blockchain*, Packt Publishing.

---

## Module 4: Permissioned Blockchains & Hyperledger Fabric

### Topics Covered
- **Permissioned Blockchains**: Public vs Private vs Consortium blockchains, Use cases for enterprise blockchains.
- **Hyperledger Fabric Architecture**: Hyperledger project overview, Hyperledger Fabric components (Peers, Endorsing peers, Orderer nodes, Certificate Authority), Channels, Chaincode (Smart contracts in Go/Node.js), Transaction flow (Endorsement, Ordering, Commit).

### Prescribed Textbooks
- Text Book 1: Imran Bashir, *Mastering Blockchain*, Packt Publishing.

---

## Module 5: Decentralized Applications (dApps) & Use Cases

### Topics Covered
- **dApp Architecture**: Decentralized Storage (IPFS - InterPlanetary File System), Web3.js / Ethers.js integration, Wallet connectors (MetaMask).
- **DeFi & Industry Applications**: Decentralized Finance (DeFi) primitives, Token standards (ERC-20, ERC-721 NFTs), Blockchain applications in Supply Chain Tracking, Healthcare records, Identity management, Real estate, Legal/Regulatory challenges.

### Prescribed Textbooks
- Text Book 1: Imran Bashir, *Mastering Blockchain*, Packt Publishing.
