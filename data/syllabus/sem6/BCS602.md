# BCS602 — Machine Learning

- **Semester**: 6th Semester B.E. (CSE Core)
- **Course Code**: BCS602
- **Credits**: 4 (3:2:0:0)
- **Total Teaching Hours**: 50 Hours (10 Hours per module)
- **Evaluation**: Continuous Internal Evaluation (CIE): 50 Marks | Semester End Exam (SEE): 50 Marks

---

## Module 1: Introduction to Machine Learning & Data Preprocessing

### Topics Covered
- **Introduction**: Need for Machine Learning, ML vs Traditional Programming, Supervised, Unsupervised, Semi-supervised, and Reinforcement Learning.
- **ML Pipeline & Data Analysis**: Big Data analysis framework, Descriptive statistics (Mean, Median, Mode, Variance, Standard Deviation), Univariate data analysis, Data pre-processing (Handling missing values, Outlier detection, Feature Scaling: Standardization vs Normalization).

### Prescribed Textbooks
- Text Book 1: S. Sridhar, M. Vijayalakshmi, *Machine Learning*, Oxford University Press.
- Text Book 2: Tom M. Mitchell, *Machine Learning*, McGraw-Hill Education.

---

## Module 2: Learning Theory, Feature Engineering & Dimensionality Reduction

### Topics Covered
- **Concept Learning & Learning Systems**: Designing a Learning System, Find-S Algorithm, Candidate Elimination Algorithm, Version Space.
- **Feature Engineering & Dimensionality Reduction**: Multivariate statistics, Feature selection methods, Principal Component Analysis (PCA - Covariance matrix computation, Eigenvalues/Eigenvectors derivation), Linear Discriminant Analysis (LDA).

### Prescribed Textbooks
- Text Book 1: S. Sridhar, M. Vijayalakshmi, *Machine Learning*, Oxford University Press.
- Text Book 2: Tom M. Mitchell, *Machine Learning*, McGraw-Hill.

---

## Module 3: Instance-Based Learning, Regression & Decision Trees

### Topics Covered
- **Instance-Based Learning**: K-Nearest Neighbors (KNN algorithm, Distance metrics: Euclidean, Manhattan, Minkowski), Weighted KNN, Nearest Centroid Classifier, Locally Weighted Regression (LWR).
- **Regression Models**: Simple Linear Regression, Multiple Linear Regression, Polynomial Regression, Gradient Descent optimization algorithm.
- **Decision Tree Learning**: Decision tree representation, Entropy, Information Gain, ID3 Algorithm, C4.5 algorithm, Overfitting, Tree pruning.

### Prescribed Textbooks
- Text Book 1: S. Sridhar, M. Vijayalakshmi, *Machine Learning*, Oxford University Press.
- Text Book 2: Tom M. Mitchell, *Machine Learning*, McGraw-Hill.

---

## Module 4: Probabilistic Learning & Artificial Neural Networks

### Topics Covered
- **Bayesian Learning**: Bayes Theorem, Maximum A Posteriori (MAP) hypothesis, Maximum Likelihood (ML) hypothesis, Naïve Bayes Classifier (Discrete & Continuous attributes), Bayesian Belief Networks (BBN).
- **Artificial Neural Networks (ANN)**: Biological neuron vs Perceptron, Perceptron Training Rule, Delta Rule, Multi-Layer Perceptron (MLP), Backpropagation Learning Algorithm (derivation of weight update equations), Activation Functions (Sigmoid, ReLU, Tanh, Softmax).

### Prescribed Textbooks
- Text Book 1: S. Sridhar, M. Vijayalakshmi, *Machine Learning*, Oxford University Press.
- Text Book 2: Tom M. Mitchell, *Machine Learning*, McGraw-Hill.

---

## Module 5: Unsupervised Clustering & Reinforcement Learning

### Topics Covered
- **Clustering Approaches**: Proximity measures, Partitioning Clustering (K-Means Clustering algorithm, Elbow method for K selection), Hierarchical Clustering (AGNES, DIANA, Single-linkage, Complete-linkage), Density-Based Clustering (DBSCAN algorithm, Core/Border/Noise points).
- **Reinforcement Learning**: Passive vs Active Reinforcement Learning, Q-Learning algorithm, Bellman Optimality Equation, Markov Decision Process (MDP).

### Prescribed Textbooks
- Text Book 1: S. Sridhar, M. Vijayalakshmi, *Machine Learning*, Oxford University Press.
- Text Book 2: Tom M. Mitchell, *Machine Learning*, McGraw-Hill.
