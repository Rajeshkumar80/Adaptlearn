# BCS601 — Cloud Computing

- **Semester**: 6th Semester B.E. (CSE)
- **Course Code**: BCS601
- **Credits**: 4 (3:0:2:0 - IPCC Integrated Course)
- **Total Teaching Hours**: 50 Hours (10 Hours per module)
- **Evaluation**: Continuous Internal Evaluation (CIE): 50 Marks | Semester End Exam (SEE): 50 Marks

---

## Module 1: Cloud Computing Fundamentals & Delivery Models

### Topics Covered
- **Introduction to Cloud Computing**: Definition, Characteristics of Cloud Computing, Historical Evolution, Enabling Technologies (Virtualization, SOA, Web 2.0).
- **Cloud Delivery Models**: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service (SaaS), Everything as a Service (XaaS).
- **Cloud Deployment Models**: Public Cloud, Private Cloud, Hybrid Cloud, Community Cloud.
- **Provider Ecosystem**: Major cloud providers (Amazon AWS, Microsoft Azure, Google Cloud Platform), SLAs (Service Level Agreements), Pricing models, Energy & Ecological impacts.

### Prescribed Textbooks
- Text Book 1: Rajkumar Buyya, Christian Vecchiola, S. Thamarai Selvi, *Mastering Cloud Computing*, McGraw Hill Education.

---

## Module 2: Cloud Architectures & Application Paradigms

### Topics Covered
- **Cloud Computing Architecture**: Layered Cloud Architecture Design, NIST Cloud Computing Reference Architecture, Intercloud Federation.
- **Distributed Coordination & MapReduce**: Coordination models (Apache ZooKeeper), MapReduce programming model (Map, Reduce, Shuffle), Hadoop HDFS architecture, Web Applications on Cloud, High-Performance Computing (HPC) on Cloud.

### Prescribed Textbooks
- Text Book 1: Rajkumar Buyya, Christian Vecchiola, S. Thamarai Selvi, *Mastering Cloud Computing*, McGraw Hill Education.

---

## Module 3: Virtualization Technologies & Hypervisors

### Topics Covered
- **Virtualization Fundamentals**: Concept of Virtualization, Virtualization vs Emulation, Virtualization Types (Full Virtualization, Para-Virtualization, Hardware-Assisted Virtualization, OS-level Containerization).
- **Hypervisors & Resource Management**: Virtual Machine Monitors (VMMs), Type-1 Bare-metal Hypervisors (VMware ESXi, Xen, KVM), Type-2 Hosted Hypervisors (VirtualBox, VMware Workstation), CPU/Memory/I/O Virtualization, VM Migration (Live Migration vs Cold Migration).

### Prescribed Textbooks
- Text Book 1: Rajkumar Buyya, Christian Vecchiola, S. Thamarai Selvi, *Mastering Cloud Computing*, McGraw Hill Education.

---

## Module 4: Cloud Security & Data Protection

### Topics Covered
- **Cloud Security Risks & Defense**: Infrastructure security, Network-level security, Host-level security, Identity and Access Management (IAM), Multi-factor authentication (MFA).
- **Data Protection & Compliance**: Data at rest encryption, Data in transit encryption, Storage diversity, Avoiding vendor lock-in, Cloud auditing, Compliance frameworks (SOC 2, ISO 27017, HIPAA, GDPR).

### Prescribed Textbooks
- Text Book 2: Tim Mather, Subra Kumaraswamy, Shahed Latif, *Cloud Security and Privacy: An Enterprise Perspective on Risks and Compliance*, O'Reilly Media.

---

## Module 5: Cloud Programming Platforms & Microservices

### Topics Covered
- **Cloud Programming Platforms**: Google App Engine (GAE architecture, Datastore, Task Queues), Amazon Web Services (AWS EC2, S3, DynamoDB, Lambda Serverless Functions), Microsoft Azure Cloud Services.
- **Microservices & Cloud Native**: Microservices Architecture vs Monolithic Architecture, Containers (Docker container engine, Dockerfiles, Container registries), Container Orchestration (Kubernetes deployment, Pods, Services, Ingress).

### Prescribed Textbooks
- Text Book 1: Rajkumar Buyya, Christian Vecchiola, S. Thamarai Selvi, *Mastering Cloud Computing*, McGraw Hill Education.
