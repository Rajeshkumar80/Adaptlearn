## Lab Programs List

### Program 1: Find-S Concept Learning Algorithm
Implement and demonstrate the **Find-S** algorithm for finding the most specific hypothesis based on a given set of training data samples (e.g., `EnjoySport` dataset).

### Program 2: Candidate Elimination Concept Learning Algorithm
Implement the **Candidate Elimination** algorithm to output the Version Space (Specific boundary \(S\) and General boundary \(G\)) for a given set of training data.

### Program 3: ID3 Decision Tree Classifier
Write a Python program to build a **Decision Tree** using the ID3 algorithm for a classification dataset. Calculate Information Gain and classify a new test sample.

### Program 4: Artificial Neural Network (Backpropagation)
Build an **Artificial Neural Network** with one hidden layer using the **Backpropagation** algorithm in Python (using NumPy) to solve non-linear classification problems (e.g., XOR gate or Iris dataset).

### Program 5: Naïve Bayes Classifier
Write a Python program to implement the **Naïve Bayes Classifier** for text document classification (e.g., Spam vs Ham email filtering) using `scikit-learn` / `pandas`.

### Program 6: Bayesian Network & Medical Diagnosis
Write a program to construct a **Bayesian Belief Network (BBN)** using `pgmpy` / Python for medical disease diagnosis given symptoms data.

### Program 7: K-Means & EM Clustering Algorithms
Write a Python program to implement **K-Means Clustering** and **Expectation-Maximization (EM / Gaussian Mixture Model)** algorithms on a dataset and compare their clustering performance.

### Program 8: K-Nearest Neighbors (KNN) Classifier
Implement the **K-Nearest Neighbors (KNN)** algorithm in Python to classify the Iris dataset. Compute confusion matrix, precision, recall, and accuracy metrics for different \(K\) values.

### Program 9: Locally Weighted Regression (LWR)
Write a Python program to implement non-parametric **Locally Weighted Regression (LWR)** algorithm and plot the smooth fit curve over a noisy non-linear dataset.

### Program 10: Principal Component Analysis (PCA)
Implement **Principal Component Analysis (PCA)** for dimensionality reduction on high-dimensional data (e.g., Breast Cancer dataset) and plot the 2D projected principal components.
