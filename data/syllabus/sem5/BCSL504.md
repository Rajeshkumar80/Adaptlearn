# BCSL504 — Web Technology Laboratory

- **Semester**: 5th Semester B.E. (CSE)
- **Course Code**: BCSL504
- **Credits**: 1 (0:0:2:0)
- **Total Practical Hours**: 20 Hours
- **Evaluation**: Continuous Internal Evaluation (CIE): 50 Marks | Semester End Exam (SEE): 50 Marks

---

## Lab Programs List

### Program 1: HTML Structural Tags & Formatting
Develop an HTML page using structural tags (`<h1>`-`<h6>`, `<p>`, `<hr>`, `<br>`, `<blockquote>`, `<pre>`) and text formatting styles (`<b>`, `<i>`, `<u>`, `<sub>`, `<sup>`, `<mark>`).

### Program 2: HTML Tables & Timetable Layout
Create a class timetable webpage using `<table>`, `<tr>`, `<th>`, `<td>` tags, with `rowspan` and `colspan` attributes, styled using internal CSS for row highlighting.

### Program 3: External CSS & Selectors
Design a multipage website using external stylesheet (`style.css`), applying element, class, ID, and pseudo-class selectors to style navigation menus, divs, and links.

### Program 4: HTML Forms & Responsive Input Elements
Design an interactive user registration form using input types (text, email, password, radio, checkbox, select dropdown, date, file upload) styled using CSS Flexbox.

### Program 5: HTML5 Semantic Layout
Create a webpage layout incorporating HTML5 semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) with responsive CSS grid layout.

### Program 6: JavaScript Dynamic Scientific Calculator
Develop an interactive dynamic calculator using JavaScript that performs basic arithmetic (sum, difference, product, division) along with advanced functions (square root, power, modulus, factorial).

### Program 7: JSON Objects & String Hashing in JavaScript
Implement a JavaScript program demonstrating JSON parsing, object stringification, date conversion, CSV-to-JSON format conversion, and simple string hashing (MD5/SHA256 demo).

### Program 8: PHP Backend Script & Visitor Counter
Develop a PHP script to maintain and display an updated webpage visitor counter stored in a server-side text file / MySQL database table.

### Program 9: PHP Database Operations (CRUD)
Write a PHP script connected to MySQL database to insert student records, fetch student records, and display them in an HTML table sorted by marks.

### Program 10: jQuery DOM Manipulation & AJAX Data Fetching
Implement a web application using jQuery for dynamic element show/hide animations and AJAX (`fetch` API / `$.ajax`) to load remote JSON data asynchronously without page reload.
