# BCS502 — Computer Networks

- **Semester**: 5th Semester B.E. (CSE)
- **Course Code**: BCS502
- **Credits**: 4 (3:2:0:0)
- **Total Teaching Hours**: 50 Hours (10 Hours per module)
- **Evaluation**: Continuous Internal Evaluation (CIE): 50 Marks | Semester End Exam (SEE): 50 Marks

---

## Module 1: Introduction to Data Communications & Physical Layer

### Topics Covered
- **Introduction**: Data communications, Components, Data representation, Data flow, Networks (Network criteria, Physical Structures, Network types: LAN, WAN, MAN, Internet), Protocol Layering, TCP/IP Protocol Suite, OSI Model layers.
- **Physical Layer & Switching**: Physical layer digital/analog transmission fundamentals, Guided Media (Twisted-pair, Coaxial cable, Fiber-optic cable), Unguided/Wireless Media (Radio waves, Microwaves, Infrared), Packet Switching (Datagram Networks, Virtual Circuit Networks).

### Prescribed Textbooks
- Text Book 1: Behrouz A. Forouzan, *Data Communications and Networking*, 5th Edition, Tata McGraw-Hill.

---

## Module 2: Data Link Layer & Media Access Control

### Topics Covered
- **Error Detection & Correction**: Introduction, Block Coding, Cyclic Codes (CRC - Cyclic Redundancy Check error detection), Checksum, Forward Error Correction.
- **Data Link Control (DLC)**: DLC Services, Framing (Character-oriented, Bit-oriented), Flow Control and Error Control, Connectionless and Connection-Oriented DLC protocols, HDLC (High-Level Data Link Control), Point-to-Point Protocol (PPP).
- **Media Access Control (MAC)**: Random Access (ALOHA, CSMA, CSMA/CD, CSMA/CA), Controlled Access (Reservation, Polling, Token Passing).

### Prescribed Textbooks
- Text Book 1: Behrouz A. Forouzan, *Data Communications and Networking*, 5th Edition, Tata McGraw-Hill.

---

## Module 3: Network Layer Protocols & Routing

### Topics Covered
- **Network Layer Services**: Network layer services, Packet switching, IPv4 Addressing (Classful vs Classless addressing, CIDR notation, Subnetting, Masking), IPv4 Datagram format, IPv6 Datagram format and IPv4-to-IPv6 transition mechanisms.
- **Routing Algorithms & Protocols**: Routing fundamentals, Distance Vector Routing (DVR - RIP protocol), Link State Routing (LSR - OSPF protocol), Path Vector Routing (PVR - BGP protocol), Unicast and Multicast Routing basics.

### Prescribed Textbooks
- Text Book 1: Behrouz A. Forouzan, *Data Communications and Networking*, 5th Edition, Tata McGraw-Hill.

---

## Module 4: Transport Layer Protocols

### Topics Covered
- **Transport Layer Fundamentals**: Transport Layer Services (Process-to-process communication, Multiplexing and Demultiplexing, Socket addressing, Connectionless vs Connection-oriented services).
- **Transport Protocols**: User Datagram Protocol (UDP - header format, checksum), Transmission Control Protocol (TCP - TCP services, features, segment format, 3-way handshake connection establishment and termination).
- **Flow, Error & Congestion Control**: TCP Flow Control (Sliding Window Protocol), TCP Error Control (Retransmission, Fast Retransmit), TCP Congestion Control (Slow Start, Congestion Avoidance, Fast Recovery).

### Prescribed Textbooks
- Text Book 1: Behrouz A. Forouzan, *Data Communications and Networking*, 5th Edition.
- Reference Book: Larry L. Peterson and Bruce S. Davie, *Computer Networks: A Systems Approach*, 5th Edition.

---

## Module 5: Application Layer & Network Security

### Topics Covered
- **Application Layer Protocols**: Application layer paradigm (Client-Server vs Peer-to-Peer), World Wide Web (WWW) and HTTP/HTTPS, File Transfer Protocol (FTP), Electronic Mail (SMTP, POP3, IMAP), Domain Name System (DNS - Architecture, Name Resolution, Resource Records), TELNET, Secure Shell (SSH).
- **Network Security Basics**: Fundamentals of Cryptography (Symmetric vs Asymmetric encryption), Firewalls, SSL/TLS security protocols.

### Prescribed Textbooks
- Text Book 1: Behrouz A. Forouzan, *Data Communications and Networking*, 5th Edition.
