# BCSL504 — Previous Year Practical Examination Questions (2023 & 2024)

- **Course Code**: BCSL504
- **Duration**: 3 Hours | **Max Marks**: 50

---

## Lab Exam Task Sets

### Task Set 1 (Part A)
- **Question**: Design an HTML5 webpage using semantic elements (`<header>`, `<nav>`, `<article>`, `<footer>`) to display a personal portfolio. Use CSS Flexbox to align contact details and projects grid.
- **Marks Breakdown**: HTML Structure (15 Marks), CSS Styling (15 Marks), Viva Voce (10 Marks), Record (10 Marks).

### Task Set 2 (Part B)
- **Question**: Develop a JavaScript webpage that dynamically validates a user registration form (Email regex format, password length \(\ge 8\) chars with special symbols, matching confirm password field) before submitting data to a PHP script.
- **Marks Breakdown**: JS Validation Script (20 Marks), HTML Form (10 Marks), PHP Output Handler (10 Marks), Viva (10 Marks).
