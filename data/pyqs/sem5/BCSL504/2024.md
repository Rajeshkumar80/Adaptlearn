# BCSL504 — Previous Year Practical Examination Questions (2024)

- **Course Code**: BCSL504
- **Duration**: 3 Hours | **Max Marks**: 50

---

## Lab Exam Task Sets

### Task Set 1
- **Question**: Create a PHP script connected to MySQL database `student_db`. Display an HTML form to insert Student USN, Name, Semester, and Marks. Retrieve and display all student records in an HTML table sorted by Marks in descending order.

### Task Set 2
- **Question**: Build a jQuery & AJAX web application that fetches user list from a public REST API (`https://jsonplaceholder.typicode.com/users`) asynchronously on button click and renders user cards on the page without full page refresh.
