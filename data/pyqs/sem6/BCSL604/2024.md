## Lab Exam Task Sets

### Task Set 1
- **Question**: Implement Backpropagation Artificial Neural Network in Python using NumPy (without high-level neural network libraries) to solve the XOR logic gate problem. Plot loss curve over training epochs.

### Task Set 2
- **Question**: Write a Python program to perform K-Means Clustering and EM (Gaussian Mixture) clustering on a 2D synthetic dataset. Plot and compare the cluster boundaries.
