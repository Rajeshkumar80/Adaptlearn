# BCS503 — VTU Model Question Paper 1

- **Course Code**: BCS503
- **Semester**: 5th Semester CSE
- **Time**: 3 Hours | **Max Marks**: 100

---

## Module 1

- **Q1(a)** [10 Marks | L3]: Construct a DFA accepting strings over \(\Sigma = \{a, b\}\) containing an even number of \(a\)'s and odd number of \(b\)'s.
- **Q1(b)** [10 Marks | L2]: Prove by induction that for any NFA, there exists an equivalent DFA.

---

## Module 2

- **Q2(a)** [10 Marks | L3]: Obtain a Regular Expression for the DFA using State Elimination technique.
- **Q2(b)** [10 Marks | L2]: Prove that \(L = \{a^{p} \mid p \text{ is prime}\}\) is not a regular language using Pumping Lemma.

---

## Module 3

- **Q3(a)** [10 Marks | L3]: Construct PDA for \(L = \{w w^R \mid w \in \{0, 1\}^*\}\). Trace Instantaneous Descriptions for input string `1001`.
- **Q3(b)** [10 Marks | L2]: Define Ambiguous Grammar. Show that the grammar \(S \to a S b S \mid b S a S \mid \epsilon\) is ambiguous.

---

## Module 4

- **Q4(a)** [10 Marks | L3]: Convert the grammar \(S \to A B \mid a\), \(A \to a\), \(B \to b\) into Chomsky Normal Form (CNF).
- **Q4(b)** [10 Marks | L2]: State and prove Pumping Lemma for Context-Free Languages.

---

## Module 5

- **Q5(a)** [10 Marks | L3]: Design a Turing Machine to accept Palindromes over \(\{a, b\}^*\). Trace computation for `a b b a`.
- **Q5(b)** [10 Marks | L2]: Explain Universal Turing Machine (UTM), Church-Turing Thesis, and undecidable problems.
