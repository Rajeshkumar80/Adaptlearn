# BCS502 — VTU Model Question Paper 1

- **Course Code**: BCS502
- **Semester**: 5th Semester CSE
- **Time**: 3 Hours | **Max Marks**: 100

---

## Module 1

- **Q1(a)** [10 Marks | L2]: Describe TCP/IP protocol suite 5-layer model and compare each layer's service with OSI model.
- **Q1(b)** [10 Marks | L2]: Explain Fiber Optic cable construction, light propagation modes (Single-mode, Multi-mode step-index, Multi-mode graded-index).

---

## Module 2

- **Q2(a)** [10 Marks | L3]: Explain Block Coding error detection and correction principles. Derive minimum Hamming distance required to detect \(d\) errors and correct \(c\) errors.
- **Q2(b)** [10 Marks | L2]: Explain Point-to-Point Protocol (PPP) framing format and transition states (Link Establishment, Authentication, Network Layer).

---

## Module 3

- **Q3(a)** [10 Marks | L3]: Given IP address `172.16.45.10/22`, determine Subnet Mask, Subnet Network ID, Broadcast Address, and Range of Valid Usable Host IPs.
- **Q3(b)** [10 Marks | L2]: Compare Distance Vector Routing (DVR) with Link State Routing (LSR / OSPF).

---

## Module 4

- **Q4(a)** [10 Marks | L3]: Describe TCP segment header fields in detail. Explain how TCP guarantees reliable, in-order byte stream delivery.
- **Q4(b)** [10 Marks | L2]: Discuss UDP sockets and process-to-process communication mechanism with port numbers.

---

## Module 5

- **Q5(a)** [10 Marks | L2]: Explain Domain Name System (DNS) hierarchy (Root servers, TLD servers, Authoritative DNS) and DNS caching mechanism.
- **Q5(b)** [10 Marks | L2]: Explain Cryptography basics: Public Key vs Private Key encryption, SSL/TLS handshake protocol.
