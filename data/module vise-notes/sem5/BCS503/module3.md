## Module 3: Context-Free Grammars (CFG) & Pushdown Automata (PDA)

### Context-Free Grammars

- **Informal idea**: A CFG is a set of recursive rewriting rules that generate the strings of a language. Context-free means a nonterminal can be replaced by a string of terminals and nonterminals regardless of the surrounding context.
- **Formal definition**: A CFG is a 4-tuple G = (V, T, P, S) where:
  - V = finite set of variables (nonterminals), written in capitals like A, B, S
  - T = finite set of terminals (the alphabet), disjoint from V
  - P = finite set of productions of the form A -> alpha, with A in V and alpha in (V union T)*
  - S = start symbol, S in V
- **Derivation**: If A -> beta is a production, then alpha A gamma derives alpha beta gamma in one step, written alpha A gamma => alpha beta gamma. A derivation of w is a sequence S => ... => w; the string w (all terminals) is a sentence of the grammar.
- **Language of a grammar**: L(G) = {w in T* | S =>* w}, the set of all terminal strings derivable from the start symbol.
- **Leftmost derivation**: At each step, the leftmost remaining variable is replaced. **Rightmost derivation**: the rightmost remaining variable is replaced each time. Every string that has a derivation has both a leftmost and a rightmost derivation.
- **Parse tree**: A tree representation of a derivation:
  - Root labeled S; leaves labeled by terminals or epsilon; internal nodes labeled by variables.
  - If an internal node labeled A has children labeled X1, X2, ..., Xk (in order), then A -> X1 X2 ... Xk is a production.
- **Yield of a parse tree**: The string of leaf labels read left to right; it equals the string generated by the derivation.
- **Ambiguity**: A grammar G is ambiguous if some string in L(G) has two distinct parse trees (equivalently, two distinct leftmost derivations, or two distinct rightmost derivations).
- **Inherently ambiguous language**: A language for which EVERY grammar is ambiguous. Example: L = {a^n b^m c^m | n, m >= 1} union {a^n b^n c^m | n, m >= 1} is inherently ambiguous (the overlap strings a^n b^n c^n cause the problem). Most practical languages are NOT inherently ambiguous.
- **Eliminating ambiguity**: Introduce precedence and associativity by restructuring the grammar. Worked example (2023 PYQ): E -> E + E | E * E | (E) | id is ambiguous because id + id * id has two parse trees (either + or * binds first). Fix by adding levels of precedence (see diagram below).
- **Simplification of CFGs (introduced here, algorithms in Module 4)**: eliminate useless symbols, epsilon-productions, and unit productions — these steps are performed BEFORE converting to CNF.

 Tree 1: root E -> E + E; left child id; right child E -> E * E with children id, id  (means id + (id * id))

- **Unambiguous grammar for arithmetic** (precedence: * binds tighter than +; both left-associative):
  - E -> E + T | T
  - T -> T * F | F
  - F -> (E) | id
  - id + id * id now has exactly one parse tree: E => E + T => T + T => F + T => id + T => id + T * F => ... (forces * below +).

### Pushdown Automata (PDA)

- **Informal idea**: A PDA is an NFA with a stack (unbounded memory, LIFO). The stack lets a PDA recognize non-regular languages like a^n b^n; it reads input left to right, one symbol per move, and each move may also push or pop stack symbols.
- **Formal definition**: A PDA is a 7-tuple P = (Q, Sigma, Gamma, delta, q0, Z0, F) where:
  - Q = finite set of states
  - Sigma = input alphabet (finite)
  - Gamma = stack alphabet (finite)
  - delta = transition function, delta: Q x (Sigma union {epsilon}) x Gamma -> finite subsets of Q x Gamma* (finite sets of pairs (state, string of stack symbols))
  - q0 = start state, q0 in Q
  - Z0 = start stack symbol (initial stack content), Z0 in Gamma
  - F = set of accepting (final) states, F subset of Q
- **Interpretation of a move**: delta(q, a, X) contains (p, gamma) meaning: in state q, reading input a (or epsilon if a = epsilon), with X on top of the stack, pop X, push the string gamma (its last symbol ends on top), and go to state p.
- **Instantaneous Description (ID)**: A snapshot (q, w, alpha) where q is the current state, w the remaining input, alpha the entire stack content (top at left). Example: (q0, abba, Z0).
- **Move (turnstile) notation**: (q, aw, X beta) |- (p, w, gamma beta) if (p, gamma) in delta(q, a, X). The relation |-* is the reflexive-transitive closure (zero or more moves).
- **Acceptance by final state**: L(P) = {w | (q0, w, Z0) |-* (q, epsilon, alpha) for some q in F and any stack content alpha}. Input is consumed AND state is final.
- **Acceptance by empty stack**: N(P) = {w | (q0, w, Z0) |-* (q, epsilon, epsilon) for any q}. Stack is emptied (this subsumes state); the final-state set F is irrelevant here and often omitted.
- **Equivalence theorem**: A language is accepted by some PDA by final state iff it is accepted by some PDA by empty stack. Proof in two directions:
  - Empty stack -> final state: add a new start state q0' and a new bottom symbol X0; push the old Z0 and enter q0; add a new final state qf with epsilon, X0 transitions from every old state popping X0 (the stack is empty exactly when X0 is the only symbol left).
  - Final state -> empty stack: add a new bottom symbol X0 and new states q0' (start) and qe (empty); from every final state, add epsilon, X moves that pop everything, ending in qe; qe has epsilon, X -> (qe, epsilon) moves for all X so the stack drains.
- **Deterministic PDA (DPDA)**: A PDA is deterministic if for every (q, a, X) at most one choice exists: delta(q, a, X) has at most one element, and if delta(q, epsilon, X) is non-empty then delta(q, a, X) is empty for all a (no conflict between epsilon and symbol moves). DPDAs accept the deterministic context-free languages (DCFLs), a proper subset of CFLs.
  - DPDA example: a^n b^n is a DCFL (push on a, pop on b).
  - L = {w w^R | w in {a, b}*} (palindromes of even length) is a CFL but NOT a DCFL — the PDA must guess where the middle is; a DPDA cannot know. Every regular language is accepted by a DPDA (a DFA is a DPDA that ignores its stack).

### Constructing PDAs — Standard Template

- **Template for L = {a^n b^n | n >= 1} (acceptance by empty stack)**: q0 reads a, pushes Z (Z = Z0): delta(q0, a, Z0) = {(q0, A Z0)}; delta(q0, a, A) = {(q0, A A)}. On b pop: delta(q0, b, A) = {(q0, epsilon)}. When input is done and stack shows Z0 (no A), pop the marker: delta(q0, epsilon, Z0) = {(q0, epsilon)}. Accept by empty stack.
- **Worked example (2024 PYQ)**: PDA for L = {a^n b^2n | n >= 1} by FINAL state. On each a push two stack markers (push AA); on each b pop one marker; accept when input exhausted and stack back to Z0 in a final state. Moves (state q, stack Z0 bottom marker, A counter):
  - delta(q0, a, Z0) = {(q0, A A Z0)} (push two markers per a)
  - delta(q0, a, A) = {(q0, A A A)}
  - delta(q0, b, A) = {(q1, epsilon)} (pop one marker per b)
  - delta(q1, b, A) = {(q1, epsilon)}
  - delta(q1, epsilon, Z0) = {(qf, Z0)} (enter final state when stack empty of markers)
  - Trace for a b b: (q0, abb, Z0) |- (q0, bb, A A Z0) |- (q1, b, A Z0) |- (q1, epsilon, Z0) |- (qf, epsilon, Z0). Accepted.
- **Worked example (2023 PYQ)**: PDA for L = {w c w^R | w in {a, b}*} by EMPTY STACK. State q0 pushes symbols before c; c triggers a switch to q1 (no symbol consumed on the stack); q1 pops while matching; finish by popping Z0.
  - delta(q0, a, Z0) = {(q0, a Z0)}, delta(q0, b, Z0) = {(q0, b Z0)}, delta(q0, a, a) = {(q0, a a)}, delta(q0, a, b) = {(q0, a b)}, delta(q0, b, a) = {(q0, b a)}, delta(q0, b, b) = {(q0, b b)} — push onto stack in q0.
  - delta(q0, c, a) = {(q1, a)}, delta(q0, c, b) = {(q1, b)}, delta(q0, c, Z0) = {(q1, Z0)} — switch state without touching stack.
  - delta(q1, a, a) = {(q1, epsilon)}, delta(q1, b, b) = {(q1, epsilon)} — pop matching symbols.
  - delta(q1, epsilon, Z0) = {(q1, epsilon)} — accept by emptying the stack.
  - ID trace for a b c b a: (q0, abcba, Z0) |- (q0, bcba, a Z0) |- (q0, cba, b a Z0) |- (q1, ba, b a Z0) |- (q1, a, a Z0) |- (q1, epsilon, Z0) |- (q1, epsilon, epsilon). Accepted by empty stack.

### Equivalence of CFG and PDA

- **Theorem (CFG -> PDA)**: For every CFG G there is a PDA P with L(P) = L(G) (by empty stack), built as a single-state "top-down" parser:
  - **Construction steps**:
    1. Let the PDA have a single state q (plus the starting configuration), start stack symbol S (the grammar's start symbol).
    2. For every terminal a: delta(q, a, a) = {(q, epsilon)} — matching input terminals against the stack top.
    3. For every production A -> alpha: delta(q, epsilon, A) = {(q, alpha^R)} — replace a variable on top of the stack by the reversed right-hand side (reversal so the first symbol of alpha ends up on top).
    4. Accept by empty stack. The PDA simulates a leftmost derivation: the stack holds the current sentential form (unmatched part), with the leftmost variable on top.
  - **Worked example (2024 PYQ)**: G: S -> a S b | epsilon. The PDA (accept by empty stack): delta(q, a, a) = {(q, epsilon)}, delta(q, b, b) = {(q, epsilon)}, delta(q, epsilon, S) = {(q, a S b), (q, epsilon)}. Trace for a a b b: stack starts S; choose S -> a S b: stack a S b; match 'a': stack S b; choose S -> a S b: stack a S b b; match 'a': stack S b b; choose S -> epsilon: stack b b; match 'b', 'b': stack empty. Accepted.
- **Theorem (PDA -> CFG)**: For every PDA P there is a CFG G with L(G) = L(P). Construction idea: introduce a variable [p X q] meaning "going from state p with X on top of the stack and ending in state q, the stack's net effect is to pop X". For each move delta(p, a, X) = {(r, Y1 Y2 ... Yk)} add productions [p X qk] -> a [r Y1 q1] [q1 Y2 q2] ... [q(k-1) Yk qk] for all choices of intermediate states q1..qk; the start symbol is [q0 Z0 qf]-like, and the language is the union over final states of these variables. (Statement-level understanding suffices for exams.)
- **Corollary**: A language is context-free if and only if it is accepted by some PDA. Thus CFL = exactly the languages of PDAs = exactly the languages of CFGs.

### Determinism and Language Hierarchy (Module 3 recap)

- Regular languages (subset of) DCFL (subset of) CFL.
- a^n b^n: DCFL, not regular (pumping lemma, Module 2).
- w w^R: CFL, not DCFL (needs guessing the middle).
- Palindromes with a middle marker c (w c w^R): DCFL (no guessing needed — the c reveals the middle).

### Exam-Focused Summary Points

- CFG question pattern: give derivations (leftmost/rightmost), draw parse trees, check/test ambiguity, remove ambiguity via precedence.
- PDA question pattern: define the 7-tuple, list delta rules, trace IDs for a sample string, state which acceptance mode is used. Always show the full ID sequence.
- Know both directions of CFG-PDA equivalence and the empty-stack/final-state equivalence constructions by heart.
- A PDA is nondeterministic by default; only call it DPDA if every (state, symbol, stack-top) triple has at most one move and epsilon-moves exclude symbol moves.
