# BCS503 — Course Outcomes (CO)

| CO Code | Course Outcome Description | Bloom's Level | Mapped Modules | Weightage / PO Mapping |
| :--- | :--- | :--- | :--- | :--- |
| **CO1** | Understand formal mathematical foundations of automata theory and construct Deterministic/Nondeterministic Finite Automata (DFA, NFA, \(\epsilon\)-NFA). | L3 (Apply) | Module 1 | PO1, PO2 |
| **CO2** | Design Regular Expressions, apply Pumping Lemma to prove non-regularity, and perform DFA state minimization algorithms. | L4 (Analyze) | Module 2 | PO1, PO2, PO3 |
| **CO3** | Formulate Context-Free Grammars (CFG), resolve grammar ambiguity, and construct Pushdown Automata (PDA) for context-free languages. | L3 (Apply) | Module 3 | PO1, PO2, PO3 |
| **CO4** | Convert Context-Free Grammars into Normal Forms (CNF/GNF) and evaluate CFL properties using Pumping Lemma. | L4 (Analyze) | Module 4 | PO1, PO2, PO4 |
| **CO5** | Design Turing Machines for complex computational languages and assess decidability, Halting problem, and P/NP complexity classes. | L4 (Analyze) | Module 5 | PO1, PO2, PO12 |
