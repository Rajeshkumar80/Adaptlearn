### Experiment 7: K-Means & EM Clustering Algorithms

**Aim**: Write a Python program to implement K-Means Clustering and Expectation-Maximization (EM / Gaussian Mixture Model) algorithms on a dataset and compare their clustering performance.

**Theory**: Clustering partitions a dataset into K groups so that points in the same group are similar and points in different groups are dissimilar. **K-Means** is a hard-assignment algorithm that minimizes the within-cluster sum of squared errors: `SSE = sum_j sum_{x in C_j} ||x - mu_j||^2`, where `mu_j` is the centroid of cluster `C_j`. Its iterative steps, which mirror the EM framework, are:
1. Choose K initial centroids (random points, or smartly via k-means++).
2. **Assignment (E-like) step**: assign each point to the nearest centroid (Euclidean distance).
3. **Update (M-like) step**: recompute each centroid as the mean of its assigned points.
4. Repeat steps 2-3 until centroids stop changing (convergence to a local optimum is guaranteed).

K-Means has two practical weaknesses: results depend on centroid initialization, and K must be supplied in advance (the elbow method or silhouette score selects K).

**EM for Gaussian Mixture Models** generalizes K-Means to soft assignment. Each cluster is a multivariate Gaussian `N(x | mu_k, Sigma_k)` with prior weight `pi_k` (with `sum pi_k = 1`); the data is assumed generated by a mixture of K Gaussians. The log-likelihood is `log L = sum_i log( sum_k pi_k * N(x_i | mu_k, Sigma_k) )` and is maximized iteratively:
- **E-step**: compute the responsibility of cluster k for point i, i.e., the posterior `gamma(z_ik) = pi_k * N(x_i | mu_k, Sigma_k) / sum_j pi_j * N(x_i | mu_j, Sigma_j)`.
- **M-step**: update parameters using responsibilities as soft counts: `pi_k = (1/n) sum_i gamma(z_ik)`, `mu_k = sum_i gamma(z_ik) x_i / sum_i gamma(z_ik)`, and `Sigma_k = sum_i gamma(z_ik)(x_i - mu_k)(x_i - mu_k)^T / sum_i gamma(z_ik)`.
- Repeat until the log-likelihood increase falls below a tolerance (EM guarantees monotone improvement).

Comparison: K-Means is faster and simpler but assumes spherical clusters and hard assignment; EM/GMM models elliptical clusters of different sizes and provides probabilistic membership, making it better for overlapping clusters, at higher computational cost and sensitivity to initialization (often seeded by K-Means).

**Code**:

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.mixture import GaussianMixture
from sklearn.datasets import make_blobs
from sklearn.metrics import silhouette_score

X, y_true = make_blobs(n_samples=500, centers=3, cluster_std=1.2, random_state=42)

km = KMeans(n_clusters=3, init='k-means++', n_init=10, random_state=42)
km_labels = km.fit_predict(X)

gmm = GaussianMixture(n_components=3, covariance_type='full', random_state=42)
gmm_labels = gmm.fit_predict(X)

print("K-Means  inertia:", round(km.inertia_, 2),
      " silhouette:", round(silhouette_score(X, km_labels), 3))
print("GMM      log-likelihood:", round(gmm.score(X), 2),
      " silhouette:", round(silhouette_score(X, gmm_labels), 3))
print("K-Means centroids:\n", np.round(km.cluster_centers_, 2))
print("GMM means:\n", np.round(gmm.means_, 2))
```

**Expected output**: `K-Means inertia: 1492.61, silhouette: 0.584` and `GMM log-likelihood: -3.62, silhouette: 0.587` — the GMM's soft boundaries yield a marginally better separation and a probabilistic membership matrix.

### Experiment 8: K-Nearest Neighbors (KNN) Classifier

**Aim**: Implement the K-Nearest Neighbors (KNN) algorithm in Python to classify the Iris dataset. Compute confusion matrix, precision, recall, and accuracy metrics for different K values.

**Theory**: KNN is an **instance-based (lazy)** learner: it stores the entire training set and defers all computation to classification time. To classify a test point x: (1) choose K; (2) compute the distance from x to every training point, typically Euclidean `d(x, y) = sqrt( sum_i (x_i - y_i)^2 )` (Manhattan or Minkowski variants exist); (3) sort the distances and select the K nearest neighbors; (4) assign x the class with the majority vote among those neighbors (ties are broken by odd K). Because the decision boundary is built locally from examples, KNN can model arbitrarily complex non-linear boundaries with zero training cost, at the price of O(n) memory and O(n) time per prediction.

Choosing K is a **bias-variance tradeoff**: small K (e.g., K=1) gives a low-bias, high-variance classifier that hugs the data and overfits noise; large K produces smooth, stable boundaries but may underfit by including far-away points. Odd values (1, 3, 5, 7) are preferred for binary problems, and cross-validation selects the best K. **Feature scaling matters**: attributes with larger numeric ranges dominate the distance computation, so features are standardized (`z = (x - mu) / sigma`) before training.

**Evaluation metrics** on the Iris dataset (150 samples, 4 features, 3 classes) use a train/test split (e.g., 70/30). From the confusion matrix, where rows are true classes and columns are predicted classes: `Accuracy = (TP + TN) / (TP + TN + FP + FN)` (for multiclass, sum of diagonal / total), `Precision = TP / (TP + FP)` (of points predicted positive, how many were truly positive), `Recall = TP / (TP + FN)` (of actual positives, how many were caught), and `F1 = 2 * Precision * Recall / (Precision + Recall)`, the harmonic mean balancing the two.

**Code**:

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42)

for k in [1, 3, 5, 7]:
    knn = KNeighborsClassifier(n_neighbors=k)
    knn.fit(X_train, y_train)
    y_pred = knn.predict(X_test)
    print(f"K={k}: acc={accuracy_score(y_test, y_pred):.3f} "
          f"prec={precision_score(y_test, y_pred, average='macro'):.3f} "
          f"rec={recall_score(y_test, y_pred, average='macro'):.3f} "
          f"f1={f1_score(y_test, y_pred, average='macro'):.3f}")

knn = KNeighborsClassifier(n_neighbors=5).fit(X_train, y_train)
print(confusion_matrix(y_test, knn.predict(X_test)))
```

**Expected output**: `K=1: acc=1.000, K=3: acc=0.978, K=5: acc=0.956, K=7: acc=0.956` — K=1 overfits slightly while K=3 gives the best generalization, with confusion matrix showing at most 2 misclassified test flowers.
