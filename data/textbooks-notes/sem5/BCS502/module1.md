## Module 1: Introduction to Data Communications & Physical Layer

### Data Communications: Definition and Components

- **Data communications** is the exchange of data between two devices via some form of transmission medium such as a wire cable. It is the movement of computer information from one point to another by means of electrical or optical transmission systems.
- **Effectiveness of a data communication system** depends on four fundamental characteristics:
  - Delivery: the system must deliver data to the correct destination, and only to the correct destination.
  - Accuracy: the system must deliver data accurately, without corruption or alteration.
  - Timeliness: the system must deliver data in a timely manner (real-time delivery for audio/video; late delivery is useless).
  - Jitter: refers to variation in packet arrival time. Uneven delays make audio/video quality poor; jitter must be minimized.
- **Five components of data communication** (one-mark answer):
  1. Message: the information (text, numbers, images, audio, video) to be communicated.
  2. Sender: the device that sends the message (computer, workstation, phone).
  3. Receiver: the device that receives the message.
  4. Transmission medium: the physical path (twisted-pair cable, coaxial cable, fiber-optic cable, radio waves) between sender and receiver.
  5. Protocol: a set of rules governing data communication; it represents an agreement between the communicating devices.
- A protocol must define: syntax (structure/format of data), semantics (meaning of each section of bits), and timing (when data is sent and how fast).

### Data Representation and Data Flow

- **Data representation**: Text is represented as bit patterns using codes such as Unicode (32 bits per symbol) and ASCII (7 or 8 bits per symbol). Numbers are represented directly in binary. Images are represented as bit patterns (pixel-based bitmap or vector graphic). Audio and video are represented as streams of bit patterns sampled at regular intervals.
- **Data flow** describes the direction of transmission between two devices (three modes):
  - Simplex: communication is unidirectional, only one device transmits and the other only receives (keyboard to monitor, TV broadcast). Example: the direction from a keyboard to a monitor.
  - Half-duplex: each station can both transmit and receive, but not at the same time; only one device transmits at a time (walkie-talkie).
  - Full-duplex: both stations can transmit and receive simultaneously (telephone call); the link capacity is shared in both directions.

### Networks: Criteria, Physical Structures and Topologies

- **A network** is a set of devices (often called nodes) connected by communication links. A node can be a computer, printer, or any device capable of sending and/or receiving data generated by other nodes on the network.
- **Network criteria** (must be met for a network to be useful):
  - Performance: measured by transit time (time for a message to travel from one device to another) and response time (elapsed time between an inquiry and a response). Depends on number of users, medium type, hardware, and software.
  - Reliability: measured by frequency of failure, time to recover from failure, and robustness in catastrophe.
  - Security: protection of data from unauthorized access, damage, and alteration.
- **Physical structures**: A connection can be point-to-point (dedicated link between two devices, e.g., microwave link or direct cable) or multipoint (one link shared by more than two devices, e.g., bus topology).
- **Network topology**: the geometric arrangement of links and nodes. Four basic topologies:
  - Mesh: every device has a dedicated point-to-point link to every other device. Number of links = n(n-1)/2 and number of ports per device = n-1. Advantages: no traffic problems, robust (one link failure does not disable the network), privacy, easy fault identification. Disadvantages: huge amount of cabling, expensive, difficult installation.
  - Star: each device has a dedicated point-to-point link only to a central controller (hub/switch). Advantages: less expensive than mesh, easy to install, robust (one link fails, only that link is affected). Disadvantages: whole network depends on the hub; if the hub fails, the entire network fails.
  - Bus: one long cable (backbone) acts as a shared medium; devices are connected by drop lines and taps. Advantages: easy installation, less cabling. Disadvantages: difficult reconnection and fault isolation, signal reflection, a break in the backbone takes the whole network down.
  - Ring: each device has a dedicated point-to-point connection with only its two neighbors; data travels in one direction. Advantages: easy to install and reconfigure, no signal regeneration problems. Disadvantages: unidirectional traffic, a break in the ring disables the whole network. Hybrid topologies combine two or more of these (e.g., a star backbone with bus branches).

```
[DIAGRAM: Network topologies

        [C]--[D]
```

### Network Types: LAN, WAN, MAN and the Internet

- **Local Area Network (LAN)**: privately owned, connects hosts in a single office, building or campus; size is limited to a few kilometres. LANs are cheap to install, offer high data rates (10 Mbps to 10 Gbps), and use simple topologies (bus or ring). Today a LAN is typically a wireless network or a wired star with a hub/switch.
- **Wide Area Network (WAN)**: covers a large geographic area (country or continent); may be switched (point-to-point WAN connecting two devices via a leased line) or internetworked (connecting multiple LANs by routers). WANs provide long-distance transmission of data, voice, image and video.
- **Metropolitan Area Network (MAN)**: a network of intermediate size, spanning a town or a city (e.g., cable television network, high-speed DSL lines). A MAN may be wholly owned by one company or operated as a public utility.
- **Internet**: interconnection of networks — two or more networks (typically LANs or WANs) connected by routers, forming a network of networks. An internetwork (internet) is a switched network in which a router connects multiple networks. No single agency owns the Internet; each network is administered by its owner, and the networks cooperate under a common protocol (TCP/IP).

### Protocol Layering and Layered Architecture

- **Protocol layering** divides a complex communication task into multiple simple, independent layers. Each layer uses the services of the layer immediately below and provides services to the layer immediately above.
- **Principle 1 — bidirectional communication**: if two machines communicate, each layer needs to perform the same tasks on the same layer of the other machine.
- **Principle 2 — identical objects in each layer**: the objects (packets) exchanged at each layer must be identical in both directions.
- **Advantages of layering**: decomposition of complex tasks (each layer is simpler), modularity (a layer can be changed without affecting others — e.g., replacing a wire with satellite), reusability, and easier debugging.
- **Logical connections**: the peer layers of two machines communicate with each other as if there were a direct connection (a logical or virtual link); in reality, data flows vertically down the layers of the sender, through the physical medium, and vertically up the layers of the receiver.

### OSI Model: Seven Layers

- The **OSI (Open Systems Interconnection) model** was developed by the International Organization for Standardization (ISO) in 1984 as a framework standardizing network communication into seven layers. It is a layered framework, not a protocol per se.
- Seven layers (top to bottom): Application, Presentation, Session, Transport, Network, Data Link, Physical. Mnemonic: "All People Seem To Need Data Processing".
- **Layer 7 — Application layer**: provides services to the user; enables access to network resources. Protocols: HTTP, FTP, SMTP, DNS, TELNET.
- **Layer 6 — Presentation layer**: concerned with syntax and semantics; handles translation (conversion of data format), compression, and encryption/decryption.
- **Layer 5 — Session layer**: establishes, maintains and synchronizes the interaction between communicating systems (dialog control); sets checkpoints to allow resumption of long transfers.
- **Layer 4 — Transport layer**: responsible for process-to-process delivery of the entire message; provides segmentation, reassembly, connection control, flow control and error control. Protocols: TCP, UDP.
- **Layer 3 — Network layer**: responsible for host-to-host (source-to-destination) delivery of packets across multiple networks; handles logical addressing (IP addresses) and routing. Protocols: IP, ICMP, routing protocols.
- **Layer 2 — Data Link layer**: responsible for node-to-node delivery of frames; adds the header (source/destination MAC addresses) and trailer (error detection bits) to the data packet; handles framing, flow control and error control. Protocols: Ethernet (IEEE 802.3), PPP, HDLC.
- **Layer 1 — Physical layer**: responsible for transmitting individual bits over the link; defines electrical/mechanical characteristics, data rate, bit synchronization, line configuration, and transmission mode. Devices: hubs, repeaters.

```
[DIAGRAM: OSI model (7 layers)
 Layer 7: Application   <--> (user services: HTTP, FTP, SMTP, DNS)
 Layer 6: Presentation  <--> (translation, compression, encryption)
 Layer 5: Session       <--> (dialog control, synchronization)

]
```

### TCP/IP Protocol Suite vs OSI Model

- The **TCP/IP protocol suite** is the de facto standard protocol stack for the Internet, created by Vint Cerf and Bob Kahn.
- TCP/IP model has **five layers** (hybrid model used in the textbook): Application, Transport, Network, Data Link, Physical. The older four-layer model merges Data Link and Physical into the Network Access layer.
- In the five-layer TCP/IP model: the Application layer combines the duties of OSI Application, Presentation and Session layers; Transport, Network, Data Link and Physical layers map directly on to OSI layers 4, 3, 2, 1.
- **Key differences** (two-mark answer):
  - OSI model is a theoretical reference model; TCP/IP is a practical protocol suite actually used on the Internet.
  - OSI has 7 layers; TCP/IP has 5 (or 4) layers.
  - In OSI, the Network layer supports both connectionless and connection-oriented services; in TCP/IP, the Network (Internet) layer is strictly connectionless.
  - In OSI, the Transport layer offers both; in TCP/IP the connection-oriented TCP and connectionless UDP are defined at Transport.
  - In OSI, layers communicate via interfaces only; in TCP/IP, protocols are the real implementations.

### Physical Layer: Digital and Analog Transmission

- The **physical layer** is responsible for moving individual bits from one node to the next; it oversees both the physical characteristics of the medium (connectors, cable type) and the encoding of data onto the signal.
- **Data** can be represented as analog (continuous waveform, e.g., human voice) or digital (discrete values, e.g., computer data).
- **Signals**: an analog signal has infinitely many levels over a continuous range; a digital signal has a limited number of defined levels (usually two: binary 0 and 1).
- **Periodic analog signals** are characterized by amplitude (peak value of the signal), period/frequency (number of periods per second, measured in hertz), and phase (position of the waveform relative to time zero). Composite signals are made of multiple sine waves.
- **Digital transmission**: data is converted to a bit stream and transmitted as discrete pulses. Digital signals are less susceptible to noise, can be regenerated (repeaters), and are cheaper.
- **Analog transmission**: data is transmitted as a continuous waveform (e.g., traditional telephone voice). Analog signals attenuate and pick up noise, requiring amplifiers; amplifier-gained noise cannot be removed.
- **Data rate vs signal rate**: data rate is the number of bits per second (bps); the signal (baud) rate is the number of signal elements per second (baud).

### Guided Media (Wired Transmission)

- **Guided (wired) media** carry electromagnetic signals through a solid physical medium: twisted-pair, coaxial, and fiber-optic cables.
- **Twisted-pair cable**: two conductors (copper wires) twisted in a spiral to cancel out electromagnetic interference (EMI) and cross-talk between neighboring pairs. Types:
  - UTP (Unshielded Twisted Pair): cheap, easy to install, widely used in telephone lines and Ethernet LANs; susceptible to noise — categories from Cat 3 (16 Mbps) up to Cat 7 (10 Gbps).
  - STP (Shielded Twisted Pair): has a metal foil or braided shield around the pairs for better noise protection, but is more expensive.
- **Coaxial cable**: a central copper core surrounded by an insulator, a braided metallic shield, and an outer plastic cover. Carries higher frequencies than twisted pair; used in cable TV (RG-59, RG-58 for Ethernet, RG-11 for long runs); offers better shielding and higher bandwidth.
- **Fiber-optic cable**: transmits signals in the form of light pulses along a glass or plastic core, using the principle of total internal reflection. Three parts: core, cladding (reflects light back into the core), and jacket. Types: multimode (step-index and graded-index) and single-mode.
  - Advantages: higher bandwidth (up to Gbps), immunity to electromagnetic interference, low attenuation over long distances, more secure (hard to tap), thinner and lighter.
  - Disadvantages: expensive connectors and installation, fragile, needs specialist splicing.
  - Applications: backbone networks, cable TV distribution, long-haul telephone trunks, LANs.

### Unguided Media (Wireless Transmission)

- **Unguided (wireless) media** transmit electromagnetic waves without a physical conductor; the medium is free space. Transmission is termed infrared, radio wave, or microwave depending on frequency.
- **Radio waves**: frequencies 3 kHz to 1 GHz; omnidirectional antennas — waves propagate in all directions, so the sending and receiving antennas need not be aligned. Used for broadcast radio, paging, AM/FM; good for long-distance, penetrate walls. The radio spectrum is regulated by national bodies.
- **Microwaves**: frequencies 1 GHz to 300 GHz; unidirectional (parabolic dish antennas must be precisely aligned). Microwaves do not penetrate walls; they are used in point-to-point links, satellite communication, and Wi-Fi/WiMAX. Repeaters (every ~35 km) are needed because of line-of-sight limitations and attenuation.
- **Infrared**: frequencies 300 GHz to 400 THz; short-range, cannot penetrate walls (a security feature); used in IR remotes, infrared LANs, short-range device communication (IrDA). Directional, so sender and receiver must be aligned.

### Packet Switching: Datagram Networks and Virtual Circuit Networks

- **Packet switching**: a network in which data is divided into smaller blocks (packets) that travel independently and are reassembled at the destination. Today's Internet uses packet switching; it makes efficient use of network resources by sharing links.
- **Datagram network** (connectionless packet switching): each packet is routed independently; each packet carries the full destination address. Packets of one message may follow different paths, arrive out of order, and be dropped if a router fails (no QoS guarantee). The network layer treats each packet separately. Example: the IP-based Internet.
- **Virtual circuit (VC) network** (connection-oriented packet switching): a connection (virtual circuit) is established before data transfer; a path from source to destination is set up and each packet carries only a VC identifier (VCI), not the full address. All packets follow the same path; setup, data transfer, and teardown are the three phases. In case of node failure, the VC is broken. Examples: X.25, Frame Relay, ATM.
- **Comparison** (two-mark answer): datagram offers better sharing of links and is more robust to failures (packets re-route around a failed node), but packets may arrive out of order and delay varies; virtual circuit provides ordered delivery, predictable QoS, and less per-packet overhead, but wastes bandwidth on the setup phase and is vulnerable to failure along the fixed path.
