## 🎯 Course Objectives

1. Understand the fundamentals of Object Oriented Programming principles using C++.
2. Apply class abstractions, data hiding, encapsulation, and constructors/destructors.
3. Implement code reusability using inheritance and runtime polymorphism via virtual functions.
4. Master C++ generic programming with function templates and class templates.
5. Learn C++ Standard Template Library (STL) containers, algorithms, and exception handling.

---

## 📚 Module-Wise Syllabus

### Module 1: Principles of OOP & C++ Basics
- Review of Procedure Oriented Programming vs Object Oriented Programming
- Basic concepts of OOP: Objects, Classes, Data Abstraction, Encapsulation, Inheritance, Polymorphism
- C++ program structure, Tokens, Expressions, and Control Structures
- Functions in C++: Function prototyping, Call by reference, Return by reference
- Inline functions, Default arguments, Const arguments, Function Overloading

### Module 2: Classes, Objects & Constructors
- Specifying a Class, Creating Objects, Accessing Class Members (public, private, protected)
- Defining Member Functions inside and outside class definition
- Static Data Members and Static Member Functions
- Array of Objects, Objects as function arguments, Friendly functions (Friend function and Friend class)
- Constructors: Default, Parameterized, Copy Constructor, Dynamic Constructors
- Destructors and order of destruction

### Module 3: Operator Overloading and Type Conversions
- Concept of Operator Overloading, Rules for Overloading Operators
- Overloading Unary Operators, Overloading Binary Operators using Member Functions and Friend Functions
- Manipulation of Strings Using Operators
- Type Conversions: Basic type to Class type, Class type to Basic type, One Class type to another Class type

### Module 4: Inheritance & Virtual Functions (Polymorphism)
- Inheritance: Defining Derived Classes, Single, Multilevel, Multiple, Hierarchical, and Hybrid Inheritance
- Virtual Base Classes, Abstract Classes, Constructors in Derived Classes
- Pointers to Objects, this pointer, Pointers to Derived Classes
- Virtual Functions, Pure Virtual Functions, Runtime Polymorphism

### Module 5: Templates, STL & Exception Handling
- Class Templates and Function Templates, Overloading of Template Functions
- Introduction to Standard Template Library (STL): Components of STL — Containers (vector, list, map), Iterators, Algorithms
- Basics of Exception Handling: try, catch, and throw mechanisms
- Rethrowing an exception, Specifying exceptions
