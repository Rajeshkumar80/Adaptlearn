## 🎯 Course Objectives

1. Demonstrate the need for an Operating System and identify different types of OS.
2. Discuss suitable techniques for managing system resources (processor, memory, storage, file systems).
3. Demonstrate the use of APIs and commands related to OS resource management.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Operating Systems
- System structures, OS operations, process/memory/storage management
- Protection and security, distributed and special-purpose systems
- OS services, user-OS interface, system calls, system programs
- OS design and implementation, virtual machines, and system boot

### Module 2: Process Management & Scheduling
- Process concept, process states, PCB
- Operations on processes, inter-process communication
- Multi-threaded programming — models, libraries, issues
- **CPU Scheduling:** FCFS, SJF, Priority, Round Robin, Multilevel Queue

### Module 3: Process Synchronization & Deadlocks
- **Synchronization:** Critical section problem, Peterson's solution
- Hardware support for synchronization
- Semaphores and classical synchronization problems (producer-consumer, readers-writers, dining philosophers)
- **Deadlocks:** Characterization, prevention, avoidance (Banker's algorithm), detection, and recovery

### Module 4: Memory & Virtual Memory Management
- **Memory Management:** Swapping, contiguous allocation, paging, segmentation
- **Virtual Memory:** Demand paging, copy-on-write
- Page replacement algorithms (FIFO, Optimal, LRU)
- Allocation of frames, thrashing

### Module 5: Storage & File System Management
- File concept, access methods, directory structure
- File system implementation, allocation methods
- Free-space management
- Mass-storage structure, disk scheduling (FCFS, SSTF, SCAN, C-SCAN)
