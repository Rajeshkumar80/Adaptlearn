## 🎯 Course Objectives

1. Explain the fundamental features and object-oriented concepts of Java programming.
2. Analyze the working of operators and control statements in Java.
3. Develop programs based on OOP principles such as polymorphism and inheritance.
4. Describe and implement packages and exception handling mechanisms.

---

## 📚 Module-Wise Syllabus

### Module 1: Overview, Data Types, and Operators
- **Java Overview:** Object-oriented programming paradigms, abstraction, and OOP principles
- **Lexical Issues:** Whitespace, identifiers, literals, comments, keywords
- **Data Types, Variables, Arrays:** Primitive types, type conversion, casting, arrays
- **Operators:** Arithmetic, relational, logical, assignment operators
- **Control Statements:** Selection (if, switch), iteration (for, while, do-while), jump (break, continue, return)

### Module 2: Classes and Methods
- **Class Fundamentals:** Declaring objects, methods, constructors, `this` keyword
- **Methods and Classes:** Method overloading, objects as parameters, argument passing, returning objects, recursion
- **Access Control:** public, private, protected
- **Advanced:** Garbage collection, `static` keyword, `final` keyword, nested/inner classes, `String` class

### Module 3: Inheritance and Interfaces
- **Inheritance:** Basics, `super` keyword, multilevel hierarchy, constructor execution order
- Method overriding, dynamic method dispatch, abstract classes
- Using `final` with inheritance
- **Interfaces:** Defining interfaces, default methods, static methods, private interface methods

### Module 4: Packages and Exception Handling
- **Packages:** Definition, member access, importing packages
- **Exception Handling:** Fundamentals, exception types
- `try-catch` blocks, multiple catch clauses, nested try
- `throw`, `throws`, and `finally`
- Creating custom exception classes
