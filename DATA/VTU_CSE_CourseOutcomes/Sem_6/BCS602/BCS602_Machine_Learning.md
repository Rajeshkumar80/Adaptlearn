## 🎯 Course Objectives

1. Understand foundational concepts of Machine Learning, problem formulation, and learning types.
2. Master supervised learning algorithms for regression and classification tasks.
3. Analyze probabilistic learning models including Naive Bayes and Bayesian Networks.
4. Learn unsupervised learning algorithms for clustering and dimensionality reduction.
5. Understand ensemble techniques, neural networks, and model evaluation protocols.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Machine Learning & Concept Learning
- Definition of Learning, Well-Posed Learning Problems, Designing a Learning System
- Perspectives and Issues in Machine Learning, Types of ML: Supervised, Unsupervised, Reinforcement Learning
- Concept Learning: Concept learning task, General-to-Specific ordering of hypotheses
- Find-S Algorithm: Finding maximally specific hypothesis, Inductive bias
- Candidate-Elimination Algorithm: Version space, Representation of boundary sets (G and S)
- Inductive Bias in Concept Learning, Unbiased learner, Active learning overview

### Module 2: Decision Tree Learning & Linear Models
- Decision Tree Representation: Appropriate problems for decision tree learning
- ID3 Algorithm: Entropy, Information Gain, Best attribute selection
- C4.5 Extensions: Gain Ratio, Handling continuous-valued attributes, Handling training data with missing attribute values
- Overfitting in Decision Trees: Avoiding overfitting, Reduced-error pruning, Rule post-pruning
- Linear Regression: Simple and Multiple Linear Regression, Cost function, Gradient Descent algorithm
- Logistic Regression: Sigmoid function, Decision boundary, Cost function, Odds ratio

### Module 3: Bayesian Learning & Instance-Based Learning
- Bayes Theorem and Concept Learning: Maximum A Posteriori (MAP) and Maximum Likelihood (ML) hypotheses
- Minimum Description Length (MDL) Principle
- Bayes Optimal Classifier, Gibbs Algorithm
- Naive Bayes Classifier: Conditional independence assumption, Text classification with Naive Bayes
- Bayesian Belief Networks (BBN): Conditional independence in DAGs, Representation of CPTs
- Instance-Based Learning: k-Nearest Neighbor (k-NN) algorithm, Distance metrics, Curse of dimensionality, Locally weighted regression

### Module 4: Support Vector Machines & Ensemble Learning
- Support Vector Machines (SVM): Maximum margin hyperplanes, Linear SVM, Support vectors
- Soft Margin SVM: Slack variables, Handling non-separable datasets
- Kernel Methods: Kernel trick, Polynomial kernel, Radial Basis Function (RBF) kernel, Mercer's condition
- Ensemble Methods: Rationale behind ensembles, Diversity in ensembles
- Bagging: Bootstrap aggregating, Random Forests (Feature bagging, Out-of-bag error)
- Boosting: AdaBoost algorithm, Gradient Boosting (GBM, XGBoost concepts), Stacking

### Module 5: Unsupervised Learning, Neural Networks & Evaluation
- Clustering: Partitional Clustering (k-Means, k-Medoids, choosing k via Elbow method)
- Hierarchical Clustering: Agglomerative vs Divisive, Dendrograms, Linkage criteria (Single, Complete, Average)
- Dimensionality Reduction: Principal Component Analysis (PCA) — Eigenvectors, Eigenvalues, Explained variance ratio
- Artificial Neural Networks (ANN): Biological neuron analogy, Perceptron, Activation functions (Sigmoid, ReLU, Tanh), Multilayer Perceptron (MLP), Backpropagation algorithm
- Model Evaluation Metrics: Confusion Matrix, Accuracy, Precision, Recall, F1-Score, ROC-AUC curve, Cross-Validation (k-fold, Stratified)
