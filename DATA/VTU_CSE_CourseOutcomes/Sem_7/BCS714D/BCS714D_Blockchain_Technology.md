## 🎯 Course Objectives

1. Understand cryptographic building blocks, hashing, digital signatures, and distributed ledger technology.
2. Analyze decentralized consensus protocols including Proof of Work (PoW) and Proof of Stake (PoS).
3. Master Ethereum virtual machine (EVM) architecture and Solidity smart contract programming.
4. Implement enterprise distributed applications using Hyperledger Fabric permissioned networks.
5. Evaluate blockchain scalability, DeFi protocols, token standards, and cybersecurity audits.

## 📚 Module-Wise Syllabus

### Module 1: Cryptographic Foundations & Blockchain Basics
- History and Philosophy of Decentralized Systems, Bitcoin whitepaper
- Cryptographic Hash Functions: SHA-256, Merkle Trees, Hash Pointers
- Public Key Cryptography: Asymmetric keys, ECDSA, Digital Signatures, Key derivation
- Blockchain Architecture: Blocks, Transactions, Nonce, Genesis Block, Block Chaining
- Distributed Ledgers: Peer-to-Peer networks, Node discovery, Transaction propagation

### Module 2: Consensus Protocols & Cryptocurrency Ecosystems
- The Byzantine Agreement Problem, Distributed Fault Tolerance
- Proof of Work (PoW): Hashcash, Mining difficulty adjustment, Incentives and Mining pools
- Proof of Stake (PoS): Validation, Slashing, Energy efficiency advantages
- Alternative Consensus: PBFT, Raft, Delegated Proof of Stake (DPoS), Proof of Elapsed Time (PoET)
- Bitcoin Ecosystem: UTXO model, Script execution, Segregated Witness (SegWit), Lightning Network

### Module 3: Ethereum Architecture & Solidity Smart Contracts
- Ethereum Overview: State machine concept, EVM execution environment, Gas model
- Smart Contracts: Deterministic execution, Contract deployment, ABI (Application Binary Interface)
- Solidity Programming: Syntax, Value types, Reference types, Mappings, Structs, Modifiers
- Events, Error Handling (assert, require, revert), Constructor, Fallback/Receive functions
- Development Tooling: Remix IDE, Hardhat, Ethers.js, MetaMask integration

### Module 4: Permissioned Enterprise Blockchains (Hyperledger Fabric)
- Permissioned vs Permissionless Networks: Use cases and trade-offs
- Hyperledger Fabric Architecture: Ordering service, Peers (Endorsing, Committing), MSP, Channels
- Chaincode Development: Writing smart contracts in Go/Node.js, Chaincode lifecycle
- Endorsement Policies, Transaction flow from client proposal to ledger commit
- Privacy and Confidentiality in Fabric: Private data collections, Channel isolation

### Module 5: Security, Tokenomics & Decentralized Applications
- Smart Contract Security: Reentrancy bugs (The DAO hack), Integer overflow/underflow, Front-running
- Token Standards: ERC-20 (Fungible tokens), ERC-721 / ERC-1155 (Non-Fungible Tokens NFTs)
- Decentralized Finance (DeFi): Decentralized Exchanges (DEXs / AMMs), Stablecoins, Lending protocols
- Decentralized Autonomous Organizations (DAOs): Governance tokens, Voting mechanics
- Enterprise Applications: Supply chain traceability, Digital identity, Intellectual property management
