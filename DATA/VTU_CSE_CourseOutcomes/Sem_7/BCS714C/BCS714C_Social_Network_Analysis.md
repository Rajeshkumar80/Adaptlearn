## 🎯 Course Objectives

1. Understand topological representations of social networks and graph theory fundamentals.
2. Analyze centrality measures, network cohesion, and structural prestige in complex networks.
3. Detect communities, cliques, and modularity in large-scale social graphs.
4. Model information cascades, epidemic diffusion, and influence propagation across networks.
5. Apply graph mining algorithms and machine learning to link prediction and sentiment analysis.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Social Networks & Graph Representation
- What is a Social Network? Examples (Online social networks, Collaboration networks, Citation graphs)
- Mathematical Foundations of Graphs: Vertices, Edges, Directed vs Undirected graphs, Weighted networks
- Network Representations: Adjacency matrices, Adjacency lists, Edge lists
- Network Topologies: Paths, Cycles, Connected components, Bipartite graphs
- Network Metrics: Degree distribution, Clustering coefficient, Average path length, Diameter, Small-World phenomenon (Six degrees of separation)

### Module 2: Centrality Measures & Network Cohesion
- Node Centrality Concepts: Degree Centrality, In-Degree and Out-Degree centrality
- Closeness Centrality: Formulation and interpretation
- Betweenness Centrality: Shortest path betweenness, Flow betweenness, Computational algorithms
- Eigenvector Centrality, PageRank Algorithm (Random Walk with Restarts), HITS Algorithm (Hubs and Authorities)
- Cohesion Measures: Density, Reciprocity, Transitivity, Structural Holes, Weak ties theory (Granovetter's Strength of Weak Ties)

### Module 3: Community Detection & Network Clustering
- Community Structure in Networks: Definition, Homophily, Assortative mixing
- Cliques, Cores, and Components: k-cliques, k-cores
- Modularity Metric: Definition, Formulation, Maximizing modularity
- Community Detection Algorithms: Girvan-Newman Algorithm (Edge betweenness based)
- Louvain Method for fast modularity optimization
- Overlapping Community Detection: Clique percolation method, Spectral clustering on graph Laplacians

### Module 4: Information Diffusion & Epidemic Modeling
- Spreading Phenomena on Networks: Rumors, Innovation, Diseases, Computer viruses
- Information Cascades: Herding behavior, Decision cascades under incomplete information
- Diffusion Models: Linear Threshold Model (LTM), Independent Cascade Model (ICM)
- Epidemic Spread Models: SI, SIS, and SIR (Susceptible-Infected-Recovered) models, Basic Reproduction Number (R0)
- Influence Maximization Problem: Kempe-Kleinberg-Tardos formulation, Submodularity, Greedy approximation algorithm

### Module 5: Link Prediction, Machine Learning & Applications
- Link Prediction Problem: Feature-based approaches (Common Neighbors, Jaccard's Coefficient, Adamic-Adar Index, Preferential Attachment)
- Node Embeddings and Graph Representation Learning: DeepWalk, Node2Vec
- Sentiment and Opinion Analysis in Social Media: Sentiment lexicon approaches, Emotion detection
- Visualization Tools: NetworkX (Python), Gephi for large-scale graph visualization
- Privacy and Anonymization in Social Networks: k-anonymity on graphs, De-anonymization attacks
