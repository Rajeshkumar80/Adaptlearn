## 🎯 Course Objectives

1. Understand foundational concepts of data mining, Knowledge Discovery in Databases (KDD), and data warehousing.
2. Master data preprocessing techniques including data cleaning, integration, transformation, and reduction.
3. Learn association rule mining algorithms (Apriori, FP-Growth) for market basket analysis.
4. Analyze classification and prediction algorithms (Decision Trees, Naive Bayes, SVM, k-NN).
5. Explore clustering paradigms (k-Means, Hierarchical, DBSCAN) and outlier detection methods.

## 📚 Module-Wise Syllabus

### Module 1: Data Warehousing & OLAP Technology
- Data Warehouse Definition, Characteristics (Subject-oriented, Integrated, Time-variant, Non-volatile)
- Data Warehouse vs Operational DBMS, Multitier Data Warehouse Architecture
- Data Models: Star Schema, Snowflake Schema, Fact Constellation Schema
- OLAP Operations: Roll-up, Drill-down, Slice, Dice, Pivot
- OLAP Server Architectures: ROLAP, MOLAP, HOLAP, Data Cube computation

### Module 2: Data Preprocessing & Knowledge Discovery Process
- Data Mining: Definition, Types of data mined, Major issues and challenges in Data Mining
- The KDD Process: Data Cleaning, Integration, Selection, Transformation, Mining, Pattern Evaluation, Presentation
- Data Cleaning: Handling missing values, Smoothing noisy data (Binning, Regression, Clustering)
- Data Integration: Entity identification problem, Redundancy and correlation analysis (Chi-square, Correlation coefficient)
- Data Transformation: Normalization (Min-Max, Z-score, Decimal scaling), Discretization
- Data Reduction: Dimensionality reduction (PCA), Numerosity reduction, Data compression

### Module 3: Mining Frequent Patterns & Association Rules
- Market Basket Analysis: Frequent itemsets, Closed itemsets, Association rules
- Association Rule Metrics: Support, Confidence, Lift
- The Apriori Algorithm: Generating frequent itemsets using candidate generation, The Apriori property
- Improving Apriori Efficiency: Hash-based technique, Transaction reduction, Partitioning, Sampling
- FP-Growth Algorithm: Constructing FP-Tree, Mining frequent itemsets without candidate generation
- Mining Multilevel and Multidimensional Association Rules

### Module 4: Classification & Prediction Algorithms
- Classification vs Prediction, General approach to solving a classification problem
- Decision Tree Induction: Attribute selection measures (Information Gain, Gain Ratio, Gini Index), Tree pruning
- Bayesian Classification: Bayes Theorem, Naive Bayesian Classifier
- Rule-Based Classification: Sequential Covering algorithms
- Lazy Learners: k-Nearest Neighbor (k-NN) classification
- Classifier Evaluation Metrics: Accuracy, Error Rate, Sensitivity, Specificity, Precision, Recall, F1-Measure, ROC Curves

### Module 5: Clustering Analysis & Outlier Detection
- Cluster Analysis: Overview, Requirements of clustering in data mining
- Partitioning Methods: k-Means algorithm, k-Medoids algorithm (PAM), Handling scalability (CLARANS)
- Hierarchical Methods: Agglomerative vs Divisive, AGNES and DIANA, BIRCH, Chameleon
- Density-Based Methods: DBSCAN (Core points, Border points, Noise points, Eps, MinPts), OPTICS, DENCLUE
- Outlier Analysis: What are outliers? Types of outliers, Outlier detection methods (Statistical, Distance-based, Density-based LOF)
