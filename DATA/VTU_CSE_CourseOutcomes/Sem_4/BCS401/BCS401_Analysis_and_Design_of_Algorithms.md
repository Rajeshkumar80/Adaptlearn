## 🎯 Course Objectives

1. Learn methods for analyzing algorithm performance and asymptotic behavior.
2. Demonstrate algorithmic efficiency using Big-O, Big-Omega, and Big-Theta notations.
3. Apply Brute Force, Divide-and-Conquer, Greedy, and Dynamic Programming paradigms.
4. Analyze graph algorithms for traversal, connectivity, and shortest paths.
5. Understand computational complexity, intractability, and P vs NP problem classes.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction & Fundamentals of Algorithm Analysis
- Notion of Algorithm, Review of Fundamentals of Algorithmic Problem Solving
- Important Problem Types: Sorting, Searching, String processing, Graph problems, Combinatorial problems
- Analysis Framework: Measuring input size, Units for measuring run time
- Orders of Growth, Worst-case, Best-case, and Average-case efficiencies
- Asymptotic Notations and Basic Efficiency Classes: Big-oh, Big-omega, Big-theta notations
- Mathematical Analysis of Non-recursive Algorithms
- Mathematical Analysis of Recursive Algorithms and Recurrence Relations

### Module 2: Brute Force and Divide-and-Conquer
- Brute Force: Selection Sort, Bubble Sort, Sequential Search, Brute-Force String Matching
- Exhaustive Search: Traveling Salesperson Problem, Knapsack Problem, Assignment Problem
- Divide-and-Conquer: General Method, Recurrence relations and Master Theorem
- Merge Sort and Quick Sort — Implementation and Detailed Complexity Analysis
- Binary Search: Algorithm, Analysis, and Comparison with Sequential Search
- Binary Tree Traversals and related properties
- Strassen's Matrix Multiplication

### Module 3: Greedy Technique & Transform-and-Conquer
- Greedy Technique: General approach, Characteristics of Greedy Algorithms
- Minimum Spanning Trees: Prim's Algorithm, Kruskal's Algorithm
- Single-Source Shortest Paths: Dijkstra's Algorithm
- Huffman Trees and Data Compression Codes
- Transform-and-Conquer: Presorting, Balanced Search Trees (AVL Trees, 2-3 Trees)
- Heaps and Heapsort, Problem Reduction

### Module 4: Dynamic Programming
- Dynamic Programming: General Method, Principle of Optimality, Memoization vs. Tabulation
- Computing a Binomial Coefficient
- Warshall's Algorithm for Transitive Closure
- Floyd's Algorithm for All-Pairs Shortest Paths
- 0/1 Knapsack Problem and Memory Functions
- Traveling Salesperson Problem by Dynamic Programming

### Module 5: Backtracking, Branch-and-Bound & NP-Completeness
- Backtracking: General method, n-Queens problem, Hamiltonian Circuit Problem, Subset-Sum Problem
- Branch-and-Bound: General method, Assignment Problem, Knapsack Problem, Traveling Salesperson
- Limitations of Algorithm Power: Lower-Bound Arguments, Decision Trees
- Complexity Classes: P, NP, NP-Complete, and NP-Hard Problems
- Coping with limitations: Approximation Algorithms for NP-Hard Problems
