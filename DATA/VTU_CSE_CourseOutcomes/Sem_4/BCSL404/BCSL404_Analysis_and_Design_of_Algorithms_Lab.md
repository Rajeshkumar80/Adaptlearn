## 🎯 Course Objectives

1. Implement and analyze divide-and-conquer sorting algorithms (Merge Sort, Quick Sort).
2. Implement greedy algorithms for minimum spanning tree and shortest paths.
3. Implement dynamic programming solutions for optimization problems.
4. Solve combinatorial search problems using backtracking and branch-and-bound.
5. Empirically verify algorithmic time complexity across different input sizes.

---

## 📚 Module-Wise Syllabus

### Module 1: Divide-and-Conquer Sorting Algorithms
- Implementation of Quick Sort algorithm and empirical analysis of best, average, and worst case running times
- Implementation of Merge Sort algorithm and empirical verification of O(n log n) complexity
- Binary Search implementation and comparison with linear search

### Module 2: Greedy Technique Programs
- Prim's Algorithm for finding Minimum Spanning Tree of a weighted undirected graph
- Kruskal's Algorithm for Minimum Spanning Tree using Union-Find disjoint sets
- Dijkstra's Algorithm for Single Source Shortest Path problem

### Module 3: Dynamic Programming Programs
- Warshall's Algorithm for Transitive Closure of a directed graph
- Floyd's Algorithm for All-Pairs Shortest Path problem
- 0/1 Knapsack Problem implementation using dynamic programming table and memory functions

### Module 4: Backtracking Programs
- N-Queens Problem solution using backtracking and state space tree visualization
- Sum of Subsets Problem using backtracking
- Hamiltonian Circuit Problem implementation

### Module 5: Branch-and-Bound & Transform-and-Conquer
- Traveling Salesperson Problem (TSP) using Branch and Bound
- Assignment Problem using Branch and Bound
- Heap Sort algorithm implementation and performance benchmarking
