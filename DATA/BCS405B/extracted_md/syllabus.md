## 🎯 Course Objectives

1. Understand the syntax, semantics, and programming paradigms of Python.
2. Master Python data structures: Lists, Tuples, Dictionaries, and Sets.
3. Implement Object-Oriented programming concepts using Python classes and methods.
4. Work with file handling, regular expressions, and exception handling.
5. Use Python standard libraries for data processing and numerical computing.

---

## 📚 Module-Wise Syllabus

### Module 1: Python Fundamentals & Flow Control
- Python Features, Python Interpreter, Running Python Scripts
- Variables, Identifiers, Data Types: Numeric, Strings, Booleans
- Operators: Arithmetic, Comparison, Logical, Bitwise, Assignment, Identity, Membership
- Input and Output: input() function, formatted printing (f-strings)
- Flow Control: if, if-else, if-elif-else, nested conditionals
- Loops: while loop, for loop, break, continue, pass statements, range() function

### Module 2: Functions, Strings & Modules
- Functions: Defining functions, Function arguments (Positional, Keyword, Default, *args, **kwargs)
- Return values, Scope of variables: Local vs Global, Anonymous functions (Lambda functions)
- String Manipulation: Indexing, Slicing, String methods (find, replace, split, join, strip, format)
- Regular Expressions: re module, Patterns, Match, Search, Findall, Sub
- Modules and Packages: Importing built-in and user-defined modules, math, random, datetime modules

### Module 3: Data Structures (Lists, Tuples, Dictionaries, Sets)
- Lists: Creation, Indexing, Slicing, List methods (append, extend, insert, remove, pop, sort, reverse)
- List Comprehensions, Nested lists
- Tuples: Creation, Immutability, Tuple unpacking, Tuple methods
- Dictionaries: Key-Value pairs, Accessing, Modifying, Dictionary methods (keys, values, items, get, update)
- Dictionary Comprehensions
- Sets: Set operations (Union, Intersection, Difference, Symmetric Difference), Set methods

### Module 4: Object-Oriented Programming & File Handling
- Classes and Objects: Class definition, Creating instances, __init__() constructor, self parameter
- Instance variables vs Class variables, Instance methods, Class methods, Static methods
- Inheritance: Single, Multiple, Multilevel inheritance, super() method
- Method Overriding, Polymorphism, Encapsulation and Data Hiding
- File Handling: Opening, Reading, Writing, Appending text and binary files, with statement
- Exception Handling: try, except, else, finally blocks, Raising custom exceptions

### Module 5: Python Libraries for Data Handling
- Introduction to NumPy: ndarray creation, Indexing, Slicing, Mathematical operations, Broadcasting
- Introduction to Pandas: Series and DataFrame creation, Reading CSV/Excel files
- Data inspection, Filtering, Grouping, Handling missing values in Pandas
- Data Visualization with Matplotlib: Line plots, Bar charts, Histograms, Scatter plots
- Introduction to Web Scraping using Requests and BeautifulSoup
