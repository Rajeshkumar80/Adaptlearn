## 🎯 Course Objectives

1. Understand security principles: Confidentiality, Integrity, Availability (CIA triad), and threat modeling.
2. Master classical, symmetric key (AES, DES) and asymmetric key cryptography (RSA, ECC).
3. Learn cryptographic hash functions, digital signatures, message authentication codes, and PKI.
4. Analyze network security protocols: IPsec, SSL/TLS, HTTPS, and email security (PGP, S/MIME).
5. Understand system security defenses: Firewalls, Intrusion Detection Systems (IDS/IPS), and ethical hacking.

## 📚 Module-Wise Syllabus

### Module 1: Security Fundamentals & Classical Encryption
- OSI Security Architecture: Security Services, Security Mechanisms, Security Attacks (Passive vs Active attacks)
- A Model for Network Security, Threat and Risk analysis
- Classical Encryption Techniques: Substitution Ciphers (Caesar, Monoalphabetic, Playfair, Hill cipher, Polyalphabetic/Vigenère cipher)
- Transposition Ciphers (Rail fence, Row transposition), Rotor machines, Steganography
- Stream Ciphers and Block Ciphers: Principles, Feistel Cipher Structure

### Module 2: Symmetric Key Cryptography (DES, AES)
- Data Encryption Standard (DES): DES encryption algorithm, Key generation, Avalanche effect, Strength of DES
- Triple DES (3DES): Meet-in-the-middle attack, 3DES with two and three keys
- Advanced Encryption Standard (AES): Mathematical foundations (Galois Fields), AES structure (SubBytes, ShiftRows, MixColumns, AddRoundKey)
- Block Cipher Modes of Operation: Electronic Codebook (ECB), Cipher Block Chaining (CBC), Cipher Feedback (CFB), Output Feedback (OFB), Counter (CTR) mode

### Module 3: Asymmetric Cryptography & Key Management
- Principles of Public-Key Cryptosystems: Applications, Requirements for public-key cryptography
- The RSA Algorithm: Key generation, Encryption, Decryption, Security of RSA, Computational efficiency
- Diffie-Hellman Key Exchange: Algorithm, Man-in-the-Middle attack
- Elliptic Curve Cryptography (ECC): Elliptic curves over finite fields, ECDH, ECDSA
- Key Distribution: Symmetric key distribution using symmetric/asymmetric techniques, Public Key Infrastructure (PKI), Digital Certificates (X.509 standard), Certification Authorities (CA)

### Module 4: Cryptographic Hash Functions, Digital Signatures & Network Protocols
- Cryptographic Hash Functions: Applications (Message authentication, Digital signatures), Requirements and Security (Preimage resistance, Collision resistance)
- Secure Hash Algorithm: SHA-512 architecture, Message Digest generation
- Message Authentication Codes (MAC): Requirements, HMAC algorithm
- Digital Signatures: Process, Digital Signature Standard (DSS / DSA)
- Network Security Protocols: IP Security (IPsec) — AH and ESP protocols, Transport and Tunnel modes, IKE
- Transport Layer Security: SSL/TLS handshake protocol, Record protocol, HTTPS

### Module 5: System Security, Firewalls & Intrusion Detection
- Malicious Software: Viruses, Worms, Trojan horses, Ransomware, Rootkits, Botnets
- Intrusion Detection Systems (IDS): Host-based IDS (HIDS), Network-based IDS (NIDS), Signature-based vs Anomaly-based detection
- Firewalls: Design principles, Characteristics, Types of Firewalls (Packet filtering, Stateful inspection, Application-level gateway / Proxy, Circuit-level gateway)
- Demilitarized Zone (DMZ) architectures
- Ethical Hacking & Vulnerability Assessment: Port scanning (Nmap), Penetration testing stages, OWASP Top 10 web vulnerabilities
