## 🎯 Course Objectives

1. Explain the fundamentals of data structures and their applications.
2. Illustrate the representation of stacks, queues, linked lists, trees, and graphs.
3. Design and develop solutions using linear data structures.
4. Discuss applications of non-linear data structures.
5. Introduce advanced concepts such as hashing and optimal binary search trees.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Data Structures
- Data structures — classifications (primitive & non-primitive), operations
- Review of pointers and dynamic memory allocation
- Arrays, structures, and unions
- Dynamic arrays, polynomials, sparse matrices, strings

### Module 2: Stacks and Queues
- **Stacks:** Definition, dynamic array implementation
- Expression conversion (infix to postfix) and evaluation
- **Queues:** Definition, circular queues
- Dynamic array implementation of queues
- Multiple stacks and queues

### Module 3: Linked Lists and Trees
- **Linked Lists:** Singly linked lists, chains
- Linked stacks and queues, polynomials, sparse matrices
- Doubly linked lists
- **Trees:** Introduction to binary trees, tree traversals (inorder, preorder, postorder)
- Threaded binary trees

### Module 4: Advanced Trees and Graphs
- **Trees (contd.):** Binary search trees, selection trees, forests
- Disjoint sets, counting binary trees
- **Graphs:** Abstract data types, elementary graph operations (BFS, DFS)

### Module 5: Hashing and Priority Queues
- **Hashing:** Static hashing, dynamic hashing
- **Priority Queues:** Single and double-ended priority queues, leftist trees
- **Efficient Binary Search Trees:** Optimal binary search trees
