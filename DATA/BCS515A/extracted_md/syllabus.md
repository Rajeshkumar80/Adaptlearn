## 🎯 Course Objectives

1. Understand foundational concepts of Artificial Intelligence, intelligent agents, and state-space search.
2. Master uninformed and informed heuristic search strategies (A*, Greedy best-first).
3. Learn adversarial search, game-playing algorithms (Minimax, Alpha-Beta pruning), and CSPs.
4. Analyze knowledge representation paradigms: Propositional and First-Order Predicate Logic.
5. Understand probabilistic reasoning, Bayesian networks, and introductory expert systems.

## 📚 Module-Wise Syllabus

### Module 1: Introduction to AI & Problem Solving by Searching
- What is AI? Foundations and History of Artificial Intelligence, The Turing Test
- Intelligent Agents: Agents and Environments, Concept of Rationality, PEAS description of agents
- Environment Types (Observable, Deterministic, Episodic, Static, Discrete, Single-agent)
- Structure of Agents: Simple reflex, Model-based, Goal-based, Utility-based agents
- Problem-Solving Agents: Well-defined problems and solutions, Formulating problems
- Search Algorithms: Measuring problem-solving performance, Uninformed Search Strategies (BFS, DFS, Uniform Cost Search, Depth-Limited Search, Iterative Deepening Search)

### Module 2: Heuristic Search & Constraint Satisfaction Problems
- Informed (Heuristic) Search Strategies: Greedy Best-First Search, A* Search (Admissibility, Consistency, Optimality)
- Heuristic Functions: Relaxed problems, Pattern databases
- Local Search Algorithms and Optimization: Hill-Climbing search (local maxima, plateaus, ridges), Simulated Annealing, Genetic Algorithms
- Constraint Satisfaction Problems (CSP): Defining CSPs, Constraint propagation (Arc consistency / AC-3)
- Backtracking Search for CSPs, Variable ordering (MRV, Degree heuristic), Value ordering (LCV)

### Module 3: Adversarial Search & Game Playing
- Games: Optimal decisions in games, Game tree representation
- Minimax Algorithm: Principle, Recursive calculation, Mathematical analysis
- Alpha-Beta Pruning: Pruning rules, Efficiency, Move ordering
- Imperfect Real-Time Decisions: Evaluation functions, Cutting off search, Quiescence search
- Stochastic Games: Games with elements of chance (Backgammon), Expectiminimax algorithm

### Module 4: Knowledge Representation & First-Order Logic
- Knowledge-Based Agents: The Wumpus World environment
- Logic: Propositional Logic, Syntax and Semantics, Propositional Theorem Proving
- Inference Rules: Resolution, Forward Chaining, Backward Chaining in Propositional Logic
- First-Order Logic (FOL): Syntax and Semantics, Quantifiers (Universal and Existential)
- Knowledge Engineering in FOL: Unification and First-Order Inference, Generalized Modus Ponens
- Forward Chaining and Backward Chaining in First-Order Logic, Resolution in FOL

### Module 5: Uncertainty & Probabilistic Reasoning
- Acting Under Uncertainty: Handling uncertain knowledge, Basic probability notation, Axioms of probability
- Inference using Full Joint Distributions, Independence, Conditional Independence
- Bayes' Rule and its applications in diagnosis and inference
- Bayesian Networks: Semantics of Bayesian Networks, Representation of conditional distributions
- Exact Inference in Bayesian Networks: Enumeration algorithm
- Introduction to Expert Systems and Rule-Based AI architecture
