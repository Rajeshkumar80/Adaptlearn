## 🎯 Course Objectives

1. Understand foundational concepts of cryptography, distributed ledgers, and blockchain architecture.
2. Master blockchain consensus mechanisms including Proof of Work (PoW) and Proof of Stake (PoS).
3. Learn Ethereum architecture, smart contract development using Solidity, and EVM.
4. Understand permissioned blockchain networks like Hyperledger Fabric and enterprise applications.
5. Analyze blockchain security vulnerabilities, scalability solutions, and decentralized finance (DeFi).

## 📚 Module-Wise Syllabus

### Module 1: Cryptographic Foundations & Blockchain Basics
- History of Blockchain: Satoshi Nakamoto, Bitcoin whitepaper, Decentralization philosophy
- Cryptographic Hash Functions: SHA-256, Keccak-256, Collision resistance, Merkle Trees
- Public Key Cryptography: Asymmetric encryption, RSA, Elliptic Curve Cryptography (ECDSA), Digital Signatures
- Blockchain Architecture: Blocks, Block headers, Genesis block, Hash pointer chaining
- Distributed Ledger Technology (DLT): Peer-to-Peer network topology, Gossip protocol, Transaction propagation

### Module 2: Consensus Mechanisms & Bitcoin Network
- The Byzantine Generals Problem and Distributed Consensus
- Proof of Work (PoW): Mining process, Difficulty adjustment, Nonce calculation, Energy consumption
- Proof of Stake (PoS): Validator selection, Slashing mechanisms, Casper protocol
- Alternative Consensus: Delegated Proof of Stake (DPoS), Practical Byzantine Fault Tolerance (PBFT), Proof of Authority (PoA)
- Bitcoin Architecture: UTXO (Unspent Transaction Output) model vs Account model, Bitcoin scripting, Forking (Hard fork vs Soft fork)

### Module 3: Ethereum & Smart Contracts with Solidity
- Introduction to Ethereum: World Computer, Ethereum Virtual Machine (EVM), Gas mechanism (Gas limit, Gas price)
- Smart Contracts: Definition, Lifecycle, Compilation, and Deployment
- Solidity Programming Language: Data types, Variables, State variables, Functions, Modifiers, Events
- Solidity Control Structures, Error handling (require, revert, assert), Inheritance and Interfaces
- Development Frameworks: Remix IDE, Hardhat / Truffle, MetaMask wallet integration, Web3.js / Ethers.js overview

### Module 4: Permissioned Blockchains (Hyperledger Fabric)
- Public vs Private vs Consortium Blockchains: Characteristics and Trade-offs
- Hyperledger Project: Linux Foundation initiative, Hyperledger ecosystem
- Hyperledger Fabric Architecture: Membership Service Provider (MSP), Peers, Ordering Service (Orderer), Channels
- Chaincode: Smart contracts in Fabric (Go/Node.js/Java), Chaincode lifecycle
- Endorsement Policy, Transaction Flow in Hyperledger Fabric (Execute, Order, Validate, Commit)

### Module 5: Blockchain Security, Scalability & Use Cases
- Blockchain Security Attacks: 51% Attack, Double Spending, Sybil Attack, Reentrancy Attack, Front-running
- Scalability Challenges: The Blockchain Trilemma (Decentralization, Security, Scalability)
- Layer-2 Scaling Solutions: State Channels, Rollups (Optimistic and Zero-Knowledge ZK-Rollups), Sidechains
- Decentralized Finance (DeFi) & Tokens: ERC-20 Fungible Tokens, ERC-721 Non-Fungible Tokens (NFTs), Decentralized Autonomous Organizations (DAOs)
- Industry Applications: Supply Chain Tracking, Healthcare record management, Digital Identity (Sovereign ID), Land registry
