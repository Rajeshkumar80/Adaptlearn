## 🎯 Course Objectives

1. Implement basic and advanced data structures in C programming language.
2. Gain hands-on experience in dynamic memory allocation, pointers, and structures.
3. Develop programs for linear data structures: stacks, queues, and linked lists.
4. Implement non-linear data structures: trees and graphs.
5. Apply hashing and collision resolution techniques.

---

## 📚 Module-Wise Syllabus

### Module 1: Linear Data Structures (Arrays & Stacks)
- Array representation, insertion, deletion, and search operations
- Stack implementation using arrays: PUSH, POP, and DISPLAY operations
- Infix to Postfix expression conversion using Stacks
- Evaluation of Postfix expression using Stacks

### Module 2: Queues
- Linear Queue implementation using arrays
- Circular Queue implementation and condition checks (overflow/underflow)
- Double Ended Queue (Deque) and Priority Queue basics

### Module 3: Linked Lists
- Singly Linked List (SLL): Insertion, deletion, search, and display
- Implementation of Stack and Queue using Singly Linked List
- Doubly Linked List (DLL): Creation, insertion, and deletion
- Circular Singly and Doubly Linked Lists

### Module 4: Trees & Graphs
- Binary Search Tree (BST): Creation, insertion, deletion of nodes
- BST Traversal: Preorder, Inorder, Postorder traversals (Recursive & Iterative)
- Graph Representation: Adjacency Matrix and Adjacency List
- Graph Traversals: Breadth First Search (BFS) and Depth First Search (DFS)

### Module 5: Hashing & Applications
- Hash Table implementation using Linear Probing for collision resolution
- Hash functions: Division method, Mid-square method
- Applications of linked lists in polynomial addition
