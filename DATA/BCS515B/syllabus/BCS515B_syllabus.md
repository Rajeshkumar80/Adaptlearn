## 🎯 Course Objectives

1. Understand cloud computing models, virtualization technologies, and distributed data center architecture.
2. Master cloud delivery models: IaaS, PaaS, SaaS, and deployment models: Public, Private, Hybrid.
3. Learn DevOps culture, principles, tools, and the CI/CD pipeline lifecycle.
4. Master containerization technologies using Docker and container orchestration using Kubernetes.
5. Explore Infrastructure as Code (IaC), continuous monitoring, and cloud security compliance.

---

## 📚 Module-Wise Syllabus

### Module 1: Cloud Architecture & Virtualization
- Cloud Computing Fundamentals: NIST Definition, Characteristics, Benefits, and Challenges
- Cloud Service Models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service (SaaS)
- Cloud Deployment Models: Public, Private, Community, and Hybrid Clouds
- Virtualization: Hypervisors (Type 1 and Type 2), CPU, Memory, and I/O Virtualization
- Virtual Machines vs Containers, Cloud Storage systems (Object, Block, File storage)

### Module 2: Cloud Infrastructure & Major Providers
- Cloud Data Centers: Multi-tenancy, Scalability, Elasticity, High Availability
- Amazon Web Services (AWS) Overview: EC2, S3, VPC, IAM, RDS, Route 53, Lambda (Serverless)
- Microsoft Azure & Google Cloud Platform (GCP) Core Services overview
- Cloud Service Level Agreements (SLAs), Cloud economics (CapEx vs OpEx), Billing models
- Cloud Security: Shared Responsibility Model, Identity and Access Management, Encryption at rest and in transit

### Module 3: Introduction to DevOps & Version Control (Git)
- DevOps: Definition, Cultural philosophy, Benefits, Agile vs DevOps
- The DevOps Lifecycle: Plan, Code, Build, Test, Release, Deploy, Operate, Monitor
- Source Code Management with Git: Git architecture, Working directory, Staging area, Repository
- Git Commands: init, clone, add, commit, push, pull, branch, merge, rebase, cherry-pick
- Branching Strategies: GitFlow, Trunk-Based Development; Pull Requests and Code Reviews in GitHub/GitLab

### Module 4: Continuous Integration & Containerization (Docker)
- Continuous Integration / Continuous Delivery (CI/CD): Concepts, Benefits, Build automation
- Jenkins: Architecture, Controller-Agent model, Freestyle jobs, Jenkinsfile Pipeline as Code (Declarative and Scripted)
- Containerization Fundamentals: Why Docker? Docker Engine architecture
- Docker Images and Dockerfile: FROM, RUN, COPY, CMD, ENTRYPOINT, EXPOSE instructions
- Docker Container Lifecycle: run, stop, ps, rm, exec, logs; Docker Volumes and Networking
- Multi-container applications using Docker Compose

### Module 5: Orchestration (Kubernetes) & Infrastructure as Code
- Container Orchestration: Why orchestration? Introduction to Kubernetes (K8s)
- Kubernetes Architecture: Control Plane (API Server, etcd, Scheduler, Controller Manager), Worker Nodes (Kubelet, Kube-proxy, Container Runtime)
- K8s Objects: Pods, ReplicaSets, Deployments, Services (ClusterIP, NodePort, LoadBalancer), ConfigMaps, Secrets
- Infrastructure as Code (IaC): Terraform basics (Providers, Resources, State file, Plan, Apply)
- Configuration Management using Ansible: Playbooks, Modules, Inventory
- Continuous Monitoring: Prometheus and Grafana for metrics collection and dashboarding
