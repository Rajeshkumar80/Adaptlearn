## 🎯 Course Objectives

1. Understand foundational concepts, physical design, and logical design of Internet of Things (IoT).
2. Analyze IoT communication protocols at link, network, transport, and application layers (MQTT, CoAP).
3. Master sensing, actuation, and embedded prototyping with Arduino and Raspberry Pi.
4. Learn IoT data processing, edge computing, cloud IoT platforms, and data analytics.
5. Understand IoT security challenges, threat modeling, and real-world industrial IoT (IIoT) applications.

## 📚 Module-Wise Syllabus

### Module 1: Introduction to IoT & Architectural Design
- Definition and Characteristics of Internet of Things (IoT)
- Physical Design of IoT: Things in IoT, IoT Protocols overview
- Logical Design of IoT: IoT Functional Blocks, IoT Communication Models (Request-Response, Publish-Subscribe, Push-Pull, Exclusive Pair)
- IoT Communication APIs: REST-based communication APIs, WebSocket-based communication APIs
- IoT Enabling Technologies: Wireless Sensor Networks (WSN), Cloud Computing, Big Data Analytics, Embedded Systems
- IoT Levels and Deployment Templates (Level 1 to Level 6 systems)

### Module 2: IoT Networking & Communication Protocols
- Link Layer Protocols: IEEE 802.15.4 (Zigbee), Bluetooth Low Energy (BLE), Wi-Fi, LoRaWAN, Cellular (NB-IoT)
- Network / Internet Layer Protocols: IPv6, 6LoWPAN (IPv6 over Low-Power Wireless Personal Area Networks), RPL Routing
- Transport Layer Protocols: TCP, UDP, Transport layer challenges in constrained environments
- Application Layer Protocols: Message Queuing Telemetry Transport (MQTT) — Architecture, Broker, Topics, QoS levels
- Constrained Application Protocol (CoAP): Architecture, Message types (Confirmable, Non-confirmable), Comparison with HTTP and MQTT
- Extensible Messaging and Presence Protocol (XMPP) and Data Distribution Service (DDS) overview

### Module 3: IoT Hardware Platforms & Interfacing (Raspberry Pi / Arduino)
- Embedded Prototyping Hardware: Microcontroller boards (Arduino Uno/ESP32/ESP8266) vs Single Board Computers (Raspberry Pi)
- Raspberry Pi: Interfaces (GPIO, I2C, SPI, UART), Linux OS configuration
- Python Programming on Raspberry Pi: Reading digital inputs, Controlling GPIO outputs (LEDs, Relays)
- Interfacing Sensors: Temperature and Humidity sensor (DHT11/DHT22), Ultrasonic distance sensor, PIR motion sensor
- Interfacing Actuators: Servo motors, DC motors with motor drivers, Buzzers
- Interfacing Analog Sensors using ADC (MCP3008) with Raspberry Pi

### Module 4: IoT Cloud Platforms & Edge Computing
- Cloud Storage and Processing for IoT: Role of cloud computing in IoT ecosystems
- IoT Cloud Platforms: AWS IoT Core, Microsoft Azure IoT Hub, Google Cloud IoT, ThingSpeak
- Connecting IoT Devices to Cloud: Device shadows, Telemetry ingestion, Rules engine
- Data Analytics for IoT: Real-time stream processing vs batch processing, Apache Kafka and Spark Streaming introduction
- Edge and Fog Computing: Edge nodes, Benefits (low latency, bandwidth reduction, privacy), Edge AI inference

### Module 5: IoT Security, Privacy & Industrial Applications
- IoT Security Vulnerabilities: Device attacks, Network attacks, Application attacks, Lack of encryption and default credentials
- Security Architectures: Device identity, Mutual TLS authentication, Secure boot, Firmware updates over-the-air (FOTA)
- Privacy and Trust in IoT: Data protection laws, Anonymization of sensor streams
- Industrial Internet of Things (IIoT): Smart Factories, Industry 4.0, Predictive maintenance
- Smart Home and Smart City Case Studies: Smart Street Lighting, Intelligent Agriculture, Connected Healthcare systems
