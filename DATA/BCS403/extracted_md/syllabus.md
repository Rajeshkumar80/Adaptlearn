## 🎯 Course Objectives

1. Understand foundational concepts of database architectures, models, and DBMS software.
2. Design conceptual data models using Entity-Relationship (ER) and Extended ER (EER) modeling.
3. Master relational model concepts, relational algebra, and relational calculus.
4. Develop SQL queries for database definition, manipulation, complex joins, views, and triggers.
5. Apply database normalization principles, transaction management, and explore NoSQL paradigms.

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Databases & Conceptual Data Modeling
- Characteristics of the Database Approach, Actors on the scene, Workers behind the scene
- Advantages of using the DBMS Approach, Database applications
- Data Models, Schemas, and Instances; Three-Schema Architecture and Data Independence
- DBMS Component Modules and Database System Utilities
- Conceptual Modeling: Entity types, Entity Sets, Attributes, Keys
- Relationship types, Constraints (Cardinality, Participation)
- Enhanced ER (EER) Modeling: Specialization, Generalization, Aggregation

### Module 2: Relational Model & Relational Algebra
- Relational Model Concepts: Domains, Attributes, Tuples, Relations
- Relational Integrity Constraints: Domain Constraints, Entity Integrity, Referential Integrity
- Foreign Keys, Update Operations, Transactions, and Constraint Violations
- ER-to-Relational Mapping Algorithm (Entity, 1:1, 1:N, M:N, Multi-valued attributes)
- Relational Algebra: Select, Project, Rename, Union, Intersection, Set Difference, Cartesian Product
- Join Operations: Theta Join, Equijoin, Natural Join, Outer Joins, Division Operator

### Module 3: SQL — Structured Query Language
- SQL Data Definition (DDL): Schema creation, Table creation, Data types, Constraints (NOT NULL, UNIQUE, CHECK, FOREIGN KEY)
- SQL Data Manipulation (DML): INSERT, UPDATE, DELETE statements
- SQL Queries: Basic SELECT statement, WHERE clause, Pattern matching (LIKE), ORDER BY
- Aggregate Functions: COUNT, SUM, AVG, MIN, MAX; GROUP BY and HAVING clauses
- Complex Retrieval Queries: Nested subqueries, Correlated queries, EXISTS, IN, ALL, ANY
- Views in SQL: View definition, Querying views, View updates, Dropping views
- Triggers and Assertions in SQL

### Module 4: Database Normalization & Dependencies
- Informal Design Guidelines for Relational Schemas: Redundant values, Insertion/Deletion/Update Anomalies
- Functional Dependencies: Definition, Trivial and Non-trivial dependencies, Armstrong's Axioms
- Closure of a set of Functional Dependencies, Attribute Closure algorithm, Minimal Cover
- Normal Forms: First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF)
- Boyce-Codd Normal Form (BCNF): Definition, Testing, Lossless Join & Dependency Preservation Decomposition
- Multivalued Dependencies and Fourth Normal Form (4NF) overview

### Module 5: Transaction Management & NoSQL Systems
- Transaction Concept: Transaction states, Desirable properties of transactions (ACID)
- Schedules and Serializability: Conflict Serializability, Precedence Graph, View Serializability
- Concurrency Control: Two-Phase Locking (2PL), Strict 2PL, Deadlock handling (Detection and Prevention)
- Database Recovery: WAL (Write-Ahead Logging), Checkpointing, Deferred and Immediate update
- Introduction to NoSQL Databases: CAP Theorem, BASE properties, Relational vs NoSQL
- NoSQL Data Models: Document Stores (MongoDB), Key-Value Stores (Redis), Column-oriented, Graph databases
