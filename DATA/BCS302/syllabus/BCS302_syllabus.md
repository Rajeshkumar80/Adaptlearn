## 🎯 Course Objectives

1. Learn logic minimization techniques and design combinational circuits using logic gates.
2. Design and analyze sequential circuit systems, registers, and counters.
3. Apply algorithms for arithmetic operations and floating-point number representation.
4. Explain the basic processing unit, control systems, memory architecture, and mapping techniques.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Digital Design
- Binary logic, Boolean algebra, Boolean functions, and digital logic gates
- Map method (K-Maps) — 2, 3, 4, 5 variable maps
- Don't-care conditions
- NAND and NOR implementations
- Introduction to Hardware Description Language (Verilog)

### Module 2: Combinational & Sequential Logic
- **Combinational Circuits:** Adders, subtractors, decoders, encoders, multiplexers
- HDL models for combinational circuits
- **Sequential Logic:** Latches, flip-flops (SR, D, JK, T)
- Analysis of clocked sequential circuits
- State reduction and assignment

### Module 3: Basic Structure of Computers
- Functional units, basic operational concepts, and bus structures
- Performance metrics — clock rate, performance equation
- Machine instructions, instruction sequencing, and addressing modes
- Assembly language basics

### Module 4: Input/Output & Memory Organization
- **I/O Organization:** Accessing I/O devices, interrupts, DMA
- **Memory System:** Memory hierarchy, semiconductor RAM
- **Cache Memory:** Mapping techniques (direct, associative, set-associative)
- Cache performance and write policies

### Module 5: Basic Processing Unit & Pipelining
- Execution of a complete instruction
- Multiple-bus organization
- Hardwired control and microprogrammed control
- **Pipelining:** Basic concepts, pipeline performance, hazards
