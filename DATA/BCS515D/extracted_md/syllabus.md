## 🎯 Course Objectives

1. Understand fundamentals of Data Science workflow, data acquisition, and exploratory data analysis.
2. Master the R programming language, vectors, matrices, data frames, and lists.
3. Apply data wrangling, cleansing, and manipulation techniques using tidyverse and dplyr.
4. Create advanced data visualizations using ggplot2 and interactive charts.
5. Build predictive statistical and machine learning models (regression, classification, clustering) in R.

---

## 📚 Module-Wise Syllabus

### Module 1: Introduction to Data Science & R Basics
- Data Science Lifecycle: Problem definition, Data collection, Preprocessing, Modeling, Evaluation, Deployment
- Introduction to R: R console, RStudio IDE, Packages in R (CRAN, devtools)
- R Data Types: Numeric, Integer, Complex, Character, Logical
- Data Structures in R: Vectors, Factors, Matrices, Arrays, Data Frames, Lists
- Control Structures: if-else, for loops, while loops, repeat, next, break; Writing functions in R

### Module 2: Data Wrangling & Manipulation (tidyverse & dplyr)
- The Tidyverse Ecosystem: Philosophy of tidy data (tidy data principles)
- Importing Data: readr, readxl, haven packages for CSV, Excel, SPSS data
- Data Manipulation with dplyr: filter(), select(), mutate(), arrange(), summarize(), group_by()
- Piping operations with the pipe operator (%>%)
- Reshaping Data with tidyr: pivot_longer(), pivot_wider(), separate(), unite()
- Handling missing values (is.na(), na.omit()), Data type conversions

### Module 3: Exploratory Data Analysis & Visualization (ggplot2)
- Exploratory Data Analysis (EDA): Summary statistics, Central tendency, Dispersion, Skewness, Kurtosis
- Grammar of Graphics with ggplot2: Aesthetic mappings (aes), Geometric objects (geoms)
- Plot Types: Scatter plots, Line charts, Bar charts, Histograms, Density plots, Box plots
- Faceting: facet_wrap(), facet_grid()
- Customizing Plots: Scales, Color palettes, Themes, Labels, Titles
- Correlation analysis, Covariance, Heatmaps using corrplot

### Module 4: Statistical Inference & Regression in R
- Probability distributions in R (norm, binom, pois, exp)
- Hypothesis Testing in R: One-sample t-test, Two-sample t-test, Paired t-test, Chi-square test of independence
- Analysis of Variance (ANOVA): One-way and Two-way ANOVA (aov() function)
- Simple Linear Regression: Model fitting (lm()), Interpretation of coefficients, R-squared, Residual analysis
- Multiple Linear Regression: Model building, Multicollinearity (VIF), Feature selection (Stepwise regression)

### Module 5: Machine Learning & Reporting in R
- Classification Models: Logistic Regression (glm()), Decision Trees (rpart), Random Forest (randomForest)
- Model Evaluation: Confusion Matrix, Accuracy, Precision, Recall, F1-Score, ROC-AUC curve
- Unsupervised Learning: K-Means Clustering (kmeans()), Hierarchical Clustering, Elbow method for optimal k
- Dynamic Reporting with R Markdown: Markdown syntax, Code chunks, Knitting to HTML, PDF, Word
- Introduction to R Shiny: Building interactive web dashboards (UI and Server logic)
