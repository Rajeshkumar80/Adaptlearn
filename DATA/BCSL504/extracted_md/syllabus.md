## 🎯 Course Objectives

1. Gain hands-on experience in socket programming using TCP and UDP sockets.
2. Simulate local area network topologies and analyze packet delivery metrics.
3. Implement data link layer framing, error detection (CRC), and flow control protocols.
4. Simulate routing algorithms (Bellman-Ford and Dijkstra's algorithm).
5. Capture and inspect network packets using Wireshark protocol analyzer.

---

## 📚 Module-Wise Syllabus

### Module 1: Packet Sniffing & WireShark Analysis
- Introduction to Wireshark Network Analyzer: Capture filters, Display filters
- Capturing and analyzing Ethernet frames, IP packets, ICMP, ARP packets
- Analyzing TCP Three-Way Handshake, TCP Flags, Sequence and Ack numbers
- Inspecting HTTP Request and Response headers, DNS query and response transactions

### Module 2: Socket Programming (TCP & UDP)
- Implementation of TCP Client-Server communication (Echo server, Reverse string, Chat application)
- Implementation of UDP Client-Server communication (Date/Time server, Message broadcast)
- File Transfer Protocol simulation using TCP sockets

### Module 3: Error Detection & Data Link Layer Protocols
- Implementation of Cyclic Redundancy Check (CRC-CCITT / CRC-16) for error detection
- Implementation of Bit Stuffing and Character/Byte Stuffing framing algorithms
- Simulation of Stop-and-Wait and Sliding Window flow control protocols

### Module 4: Network Layer Routing Protocols
- Implementation of Distance Vector Routing algorithm using Bellman-Ford equation
- Implementation of Link State Routing algorithm using Dijkstra's shortest path algorithm
- Implementation of Leaky Bucket algorithm for network congestion control and traffic shaping

### Module 5: Network Simulation Tools (NS2 / NS3 / Cisco Packet Tracer)
- Simulation of 3-node point-to-point network and analyzing packet drops with varying queue size
- Simulation of transmission of ping messages over a network topology and measuring round-trip time
- Simulation of Ethernet LAN using n nodes and measuring throughput
