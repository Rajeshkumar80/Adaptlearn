## 🎯 Course Objectives

1. Master modern frontend development using semantic HTML5, CSS3, and JavaScript (ES6+).
2. Build reactive and component-driven user interfaces using modern frameworks (React.js).
3. Develop scalable backend RESTful APIs using Node.js and Express.js runtime.
4. Design schema models and perform CRUD operations with NoSQL databases (MongoDB / Mongoose).
5. Implement authentication, secure APIs (JWT), state management, and full-stack deployment.

---

## 📚 Module-Wise Syllabus

### Module 1: Frontend Foundations (HTML5, Modern CSS & JavaScript ES6+)
- HTML5 Semantic Elements: header, nav, main, section, article, footer
- Modern CSS: Flexbox layout, CSS Grid, Responsive Web Design, Media queries, CSS Variables
- JavaScript ES6+ Essentials: let/const, Arrow functions, Template literals, Destructuring, Spread/Rest operators
- Asynchronous JavaScript: Promises, async/await, Fetch API for HTTP requests
- DOM Manipulation and Event Handling: Event listeners, Event bubbling and delegation

### Module 2: Frontend Framework (React.js)
- Introduction to React: Virtual DOM, Component architecture, JSX syntax
- Creating Components: Functional components, Props and State management
- React Hooks: useState, useEffect, useRef, useMemo, custom hooks
- Handling Forms and Controlled Components in React
- Routing with React Router (BrowserRouter, Routes, Route, Link, useNavigate)
- State Management: Context API and introduction to Redux Toolkit

### Module 3: Backend Development with Node.js & Express.js
- Node.js Runtime: Architecture, Non-blocking I/O, Event loop, Modules (CommonJS and ESM)
- Node Package Manager (npm): package.json, scripts, dependencies vs devDependencies
- Express.js Framework: Setup, Routing, Request and Response objects
- Middleware in Express: Built-in, Third-party (cors, morgan), Custom error-handling middleware
- Building RESTful APIs: GET, POST, PUT, PATCH, DELETE endpoints with JSON payloads

### Module 4: Database Integration (MongoDB & Mongoose)
- Introduction to NoSQL and MongoDB: Document-oriented database concepts, Collections, Documents
- MongoDB Atlas (Cloud) setup and connection with Node.js driver
- Mongoose ODM: Defining Schemas, Data types, Validation rules, Models
- CRUD Operations with Mongoose: find(), findById(), create(), updateOne(), deleteOne()
- Data Relationships: Embedded documents vs Referenced documents (populate() method)

### Module 5: Authentication, Security & Deployment
- User Authentication & Authorization: Password hashing using bcrypt
- JSON Web Tokens (JWT): Structure (Header, Payload, Signature), Token generation, Verification middleware
- Web Security Best Practices: CORS configuration, Sanitizing inputs against XSS and NoSQL injection, Helmet.js
- Connecting Frontend (React) with Backend (Express): Axios HTTP client, Handling loading and error states
- Full Stack Deployment: Environment variables (.env), Production build generation, Hosting on Vercel/Render/Railway
