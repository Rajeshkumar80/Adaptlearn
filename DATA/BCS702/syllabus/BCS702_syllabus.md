## 🎯 Course Objectives

1. Understand foundational concepts of neural networks, multi-layer perceptrons, and backpropagation.
2. Master deep network training techniques, optimization algorithms (Adam, RMSProp), and regularization.
3. Learn Convolutional Neural Networks (CNN) for computer vision tasks and image classification.
4. Master Recurrent Neural Networks (RNN, LSTM, GRU) and Transformer attention mechanisms for sequential data.
5. Explore generative models including Autoencoders, GANs, and modern diffusion models.

## 📚 Module-Wise Syllabus

### Module 1: Neural Networks & Deep Learning Foundations
- Biological vs Artificial Neurons, Perceptron and Perceptron learning rule
- Multilayer Perceptron (MLP): Architecture, Forward propagation, Activation functions (Sigmoid, Tanh, ReLU, Leaky ReLU, Softmax)
- Loss Functions: Mean Squared Error (MSE), Binary Cross-Entropy, Categorical Cross-Entropy
- Backpropagation Algorithm: Mathematical derivation using chain rule of calculus
- Vanishing and Exploding Gradient problems and remedies (Weight initialization: Xavier/Glorot, He initialization)

### Module 2: Optimization & Regularization in Deep Networks
- Optimization Algorithms: Batch Gradient Descent, Stochastic Gradient Descent (SGD), Mini-batch Gradient Descent
- Momentum-based SGD, Nesterov Accelerated Gradient, RMSProp, Adam (Adaptive Moment Estimation) optimizer
- Learning Rate Scheduling: Step decay, Exponential decay, Cosine annealing
- Overfitting in Deep Networks, Regularization Techniques: L1 and L2 weight regularization (Weight decay)
- Dropout: Inverted dropout, Training vs testing behavior
- Batch Normalization: Mathematical mechanics, Benefits, Layer Normalization

### Module 3: Convolutional Neural Networks (CNNs)
- Computer Vision challenges, Convolution Operation: 2D convolution, Filters/Kernels, Stride, Padding (Valid vs Same)
- Pooling Layers: Max pooling, Average pooling
- CNN Architecture Building Blocks: Conv-ReLU-Pool sequences, Fully connected layers
- Classic CNN Architectures: LeNet-5, AlexNet, VGG-16 / VGG-19, GoogLeNet (Inception module), ResNet (Residual connections / Skip connections)
- Transfer Learning: Fine-tuning pretrained networks, Feature extraction using ImageNet models
- Applications: Image classification, Object detection concepts (YOLO, Faster R-CNN overview)

### Module 4: Recurrent Neural Networks & Attention Mechanisms
- Sequence Modeling: Unfolding computational graphs for sequential data
- Recurrent Neural Networks (RNN): Forward pass, Backpropagation Through Time (BPTT)
- Long Short-Term Memory (LSTM): Cell state, Forget gate, Input gate, Output gate mechanics
- Gated Recurrent Units (GRU): Update gate, Reset gate
- Bidirectional RNNs and Deep RNNs
- Seq2Seq Models and Attention Mechanism: Context vector calculation, Bahdanau and Luong attention, Scaled Dot-Product Attention

### Module 5: Generative Models & Transformer Architecture
- Autoencoders: Architecture, Undercomplete autoencoders, Denoising autoencoders
- Variational Autoencoders (VAEs): Latent space, Reparameterization trick, Reconstruction loss vs KL-divergence
- Generative Adversarial Networks (GANs): Generator and Discriminator game, Minimax loss function, DCGAN architecture
- The Transformer Architecture: Multi-Head Attention, Positional Encodings, Self-Attention in Vision Transformers (ViT)
- Overview of Foundation Models, Diffusion Models (Stable Diffusion concepts), and LLMs
